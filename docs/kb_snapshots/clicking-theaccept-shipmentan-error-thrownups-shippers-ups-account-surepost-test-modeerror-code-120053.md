# [Error Code:120053] – Shippers UPS Account is in SurePost test mode

In this small guide, we will help you solve the “[Error Code: 120053] – Shippers UPS Account is in SurePost Test mode” that appears when using the WooCommerce UPS Shipping Plugin with Print Label.

**Customer** :

Now, when clicking the “Step 2: Accept Shipment”, an error is thrown:”UPS: Shippers UPS Account is in SurePost test mode. [Error Code: 120053].” Now, my guess is that this needs to be taken care of by UPS? Am I correct assuming this?

* * *

**PluginHive Support** :

You’re right! [UPS SurePost](https://www.ups.com/worldshiphelp/WS15/ENU/AppHelp/SHIPMENT/About_UPS_SurePost.htm) is an account-specific service. We would request you to contact UPS to check whether SurePost service is enabled for your UPS account.
