# WPML & WooCommerce Canada Post Shipping for Multilingual Sites

In this article, we will tell you how to configure and use the **[WooCommerce Canada Post Shipping](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/)** Plugin along with the famous multilingual plugin – WPML. Read more below.

WooCommerce Canada Post plugin allows store owners to provide shipping options to their customers. The plugin provides real-time accurate shipping rates from Canada Post, based on the weight and the destination of the shipment. Moreover, WooCommerce Canada Post Shipping plugin also provides the official Canada Post Shipping labels along with the ability to track your shipments across the world. With so many world-class features, now the plugin is also compatible with the WPML plugin so that it can be used on the multilingual websites.

To harness the power of both plugins, you need to have our **[WooCommerce Canada Post Shipping](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/) **installed in your WooCommerce store and the **[WPML plugin](https://wpml.org/)**. Here are the components of the WPML plugin which you need to install separately.

  * WPML Multilingual CMS
  * WPML String Translation
  * WPML Translation Management
  * WooCommerce Multilingual
  * WPML Media
  * Multilingual Tools

### Getting Started

Once you have successfully installed the WPML plugin, you can configure it easily from **WPML >> Languages. **After that, you can follow the following steps to successfully configure the WPML plugin.

  * Select your default language.
  * Choose a set of active languages
  * Choose a language selector (For starters, choose the footer language selector; you can change this later.)
  * Install and activate all the WPML related plugins (mentioned in the first section). If you still feel you need some help in installing the WPML plugin, you can follow this **[getting started guide](https://wpml.org/documentation/getting-started-guide/) **by WPML.
  * Install the **[Canada Post WooCommerce](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/)** Shipping plugin and activate it. You can refer to the [**plugin documentation**](https://www.pluginhive.com/knowledge-base/category/woocommerce-canada-post-shipping-plugin/) on how to install and set up the plugin.
