# Pre-Paid UPS Return Label for WooCommerce Store

While shipping a product, one needs to keep in mind the scenarios where the customer might return the package. This can happen due to a number of reasons, including repair services, the products provided under rent (pawn stores), etc. However, in such cases, it becomes very convenient for the customers if the store bears the cost of shipment. Many WooCommerce store owners require a return shipment label that they can provide to their customers.

According to Jane, a WooCommerce store owner, “ _**…****We need to use shipping labels with UPS in two different ways. We require shipping labels for our products. We rent some products to the customers. And we require a pre-paid return shipping label for customers who choose to pay upfront for shipping if they plan to return ship the item from a known location address. Is this possible..? Thanks..!**_ ”

In this article, we will cover how [**WooCommerce UPS Shipping plugin** ](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)allows WooCommerce store owners to print the UPS return label.

* * *

## Return Shipping Label

WooCommerce UPS Shipping plugin is one of the best shipping plugins out there. Using this plugin, WooCommerce store owners can easily print the return shipping labels. While creating the shipment, Jane can select the**option to include a return shipping label**. The image below shows the option to get the return shipping label.

Once you enable this option, another package will be generated for that package with the same weight and dimensions. Here you can select the shipping method in case of a return shipment. The image below shows the return package with the shipping service.

Now Jane can easily generate both shipping and return shipping labels by clicking the Generate Package option. Both the shipping and return shipping labels will be generated together. The image below shows both of these shipping labels.

So this way WooCommerce store owners can generate return shipping labels using WooCommerce UPS Shipping plugin.

So this article covers the WooCommerce UPS Shipping plugin fulfilling an important shipping scenario. Online business owners are required to provide the facility to have return shipments. This article covers how using this plugin, the store owner can provide return shipping labels to their customers.
