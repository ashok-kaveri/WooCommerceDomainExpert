# Generate Return Label & Drop Package at the UPS Access Point

In this article, we will show you how to generate the return shipping label and drop our package at the UPS Access point when using the **[WooCommerce UPS Shipping Plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)**.

UPS is amongst the best shipping carrier out there when it comes to domestic and international shipping. For WooCommerce store owners, [**WooCommerce UPS Shipping plugin**](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/) provides all the amazing UPS shipping features. In this article, we will be discussing some of those amazing shipping features in detail. So the features that we will be covering are,

  * **UPS Access Point**

One of our customers was having some issues regarding the two services. According to Billy, “ _**There are quite a few returns now so we just want to include a return label with every order so the customer can return garments back to us easily. I had assumed that the plugin would generate a return label with store’s address on it and the customer could then bring that to their local UPS Store, regardless of whether it was delivered to their home or to an Access Point.**_

_**I want to generate a return label and allow my customers to drop it off at an Access Point.**_ “

So based on his requirement, this article will show how both these services are different and can be used together.

## Billy’s Confusion

Billy actually wants to use **[UPS Access Point](https://www.pluginhive.com/ups-access-point-for-ecommerce/)** functionality for his customers such that, they would select the nearest UPS-authorized access points for their package delivery. What it means is that the shipping address will contain the address of the access point.

However, his confusion was regarding the return shipment. **_Since the shipping address in the above scenario included the address of the access point, would it also be included in the ship-from address in case of a return shipment?_**

Using the WooCommerce UPS Shipping plugin, in case of the return shipment, no additional address fields are included in the ship from address. In other words, only the address entered by the customer will be taken into consideration while processing a return shipment.
