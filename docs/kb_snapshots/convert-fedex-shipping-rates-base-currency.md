# Convert WooCommerce FedEx Shipping Rates to Base Currency

In this article, we will show you how to convert the returned **[FedEx Shipping Rates](https://www.pluginhive.com/fedex-shipping-rates-on-your-woocommerce-store/)** to Base currency when using the **[WooCommerce Shipping Plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**. Read along to know more.

FedEx is one of the best and most famous shipping services in the world. And day by day, the number of people using their services to ship items is constantly multiplying. Many WooCommerce store owners are coming closer to their customers by using our WooCommerce Shipping plugin for FedEx. It works with the countries where FedEx is functional.

#### **Converting FedEx shipping rates**

WooCommerce shipping plugin for FedEx will show the FedEx shipping rates to the customers irrespective of their country only if FedEx delivers to their location. However, many store owners cannot figure out how to use this plugin for **[FedEx international shipping](https://www.pluginhive.com/fedex-international-shipping-guide-for-woocommerce-users/)** and how to show the rates in the base currency.

Let us take an example of one of our customers.

> Matt: I have an inquiry about your WooCommerce sipping plugin for FedEx. My business is located in France and we want to ship with FedEx. With other Fedex plugins they require the base currency to be in USD, but we want to use Euros. Will your plugin enable us to use Euros?

By using our plugin, store owners can configure the currency conversion rate to another country. They just need to go to the FedEx settings page and enter the currency rate in the following box.

For example, if you want to convert EUR into USD, then enter the current rate (here 1.17 as of November 2017) and save the changes that you have made.

Moreover, the FedEx API is connected to the European FedEx. This means that the API will return rates in US currency but you can use the inbuilt plugin feature to convert the rates to the base currency. The inbuilt feature is shown in the image below.

By checking this enable button, you can convert the returned rates to the base currency.

### Can you display FedEx shipping rates in Shopify?

Yes, you can. With the help of **[Shopify FedEx App](https://www.pluginhive.com/product/shopify-fedex-shipping-app-with-print-label-tracking/)** , you can display real-time FedEx shipping estimate on your Checkout page. It provides you FedEx One Rate along with FedEx Standard Rates. Moreover, you get even more shipping services like **[FedEx SmartPost](https://www.pluginhive.com/woocommerce-ups-surepost-or-fedex-smartpost-which-one-to-choose/)** , FedEx Freight services, **[FedEx Saturday delivery services](https://www.pluginhive.com/fedex-deliver-saturday-provide-accurate-estimated-delivery-dates-woocommerce-store/)** , and much more.

You can even define multiple ‘Ship from’ addresses, set a default shipping origin and create various shipping zones. Under each shipping zone, you can select the **Calculated rates** as FedEx Rates Service. Refer to the image below.
