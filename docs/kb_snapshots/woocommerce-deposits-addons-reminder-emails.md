# WooCommerce Deposits addons – Reminder emails for percentage deposits

PluginHive’s **[WooCommerce Deposits plugin](https://www.pluginhive.com/product/woocommerce-deposits/)** allows you to provide customers an option to pay a deposit upfront and pay the balance later. With this plugin, you will be able to send reminder emails for Scheduled payment plans based on the Order date. However, when you use the **[bookings plugin](https://www.pluginhive.com/product/woocommerce-booking-and-appointments/)** to accept bookings, you may need to send reminder emails based on the Booking start date. 

Using this add-on, you will be able to send the reminder email for Percentage Deposits based on the Booking start date. The setup is quite simple as shown below.

#### What does it do?

This add-on plugin allows admins to send Reminder emails for Percentage Deposits based on the Booking start date.

* * *

**_Note:_**  
Balance Payment Order Creation setting should NOT be “Create a single order for balance payment”
