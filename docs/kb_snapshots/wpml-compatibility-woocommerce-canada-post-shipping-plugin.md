# WooCommerce Canada Post Shipping Plugin with WPML Support

We have some good news! It has been over a week since PluginHive has been working alongside the WPML team to ensure the [**WooCommerce Canada Post Shipping Plugin**](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/)‘s compatibility with the WPML plugin.

* * *

## How does the WPML integration help PluginHive users?

It has been a great pleasure working with the WPML team to conduct the compatibility testing of the plugin to make sure that the **[WooCommerce Canada Post Shipping](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/)** Plugin works flawlessly with WPML. Now you can expand your online business all over the world without worrying about language translations.

* * *

### Why use WPML?

WPML has been the industry standard for more than 500,000 websites when it comes to multi**–** lingual**** translations for plugins, themes, theme options, blog posts, etc. on WordPress. Using this plugin you can provide a comprehensive **[translation of your store](https://www.pluginhive.com/woocommerce-multilingual-plugins/)** to customers all around the world.

To make your website multi-lingual so that even the Canada Post shipping rates are shown in multiple languages, you would need to purchase the **[WPML Plugin](https://wpml.org/purchase)**.

### Why use WooCommerce Canada Post Shipping Plugin?

**[WooCommerce Canada Post Shipping Plugin](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/)** by PluginHive is the best Canada Post shipping solution for WooCommerce users. The plugin provides real-time shipping rates from Canada Post for both domestic as well as international shipments. WooCommerce Canada Post Shipping plugin provides the store owners to provide the commercial invoice and also the complete Manifest for every order that has been placed.

You can check out the WPML compatibility page for our plugin and also read the documentation: **[WPML Compatibility for WooCommerce Canada Post Shipping Plugin](https://www.pluginhive.com/knowledge-base/using-wpml-woocommerce-canada-post-shipping-plugin-multilingual-sites/)**.

If you need any help setting up Canada Post shipping on your WooCommerce store, feel free to **[Contact PluginHive Customer Support](https://www.pluginhive.com/support/)**. We would be more than happy to help.
