# Install & Activate License for WooCommerce Bookings and Appointments

The [Bookings and Appointments for WooCommerce plugin ](https://www.pluginhive.com/product/woocommerce-booking-and-appointments/)is a powerful tool to set up a booking facility on your website.

In this article, we will guide you through the necessary steps that are required to install and activate the plugin.

* * *

## Installation

If you had the FREE version of Bookings and Appointments for WooCommerce installed on your site. Please deactivate and delete it before you install the Premium version. If not, please continue with the below instructions.

After purchasing the Bookings and Appointments for WooCommerce plugin, you will receive an email with the below details :

The email contains a link to Download Files, the API Licence key, and the product ID associated with the plugin.

When you click on the Download Files link you will be taken to PluginHive – > **My Account** section. (Please Login/Register into PluginHive if you haven’t logged in yet)

  1. Download the .zip file from PluginHive **My Account. – > API Downloads **

  1. Log in as the WordPress Admin of your woocommerce online store.
  2. Navigate to **Plugins** > **Add New** to upload the downloaded PluginHive Bookings and Appointments for WooCommerce.
  3. **Activate** the Bookings and Appointments for WooCommerce plugin.

You have now successfully installed and activated the plugin.

The next step is to activate the License. Please follow the below instructions to activate the license.

* * *

## License Activation

You can get the Licence activation key from the Order completion Email sent to you after the purchase or from the below path

PluginHive – > My Account -> API Keys

* * *

Go to **Bookings – > Settings – > Licence**, you will find the below license settings page.

****

* * *

Provide the API license Key and the product ID and activate

After entering the API License key and the product ID, you can click on the **Activate** button to activate the license.

With this, you are ready to start using the plugin.

* * *

You can also follow up with the below video which will show you how to install and activate the plugin

Now, in order to set up booking facilities, you have to go to the **Edit product** page of any one of your Woocommerce products. You can refer to the following link to learn how to set up bookable items.

[Setting up Bookings and Appointments for WooCommerce](https://www.pluginhive.com/knowledge-base/setup-guide-woocommerce-bookings-and-appointments-plugin/)
