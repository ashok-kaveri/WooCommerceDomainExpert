## Creating and Shipping WooCommerce Custom Product Boxes

Once you’ve installed the WooCommerce Custom Product Boxes plugin, all you need to do is create a new product that will serve as the custom assorted product. Customers can choose from all the available products on your store and create the custom products by themselves.

If you want to provide limited options to the customers, you can choose which products the customers will be able to add in this product. The image below shows the edit product page with the added option by WooCommerce Custom Product Boxes plugin.

You can easily create your newly created custom product by tweaking the options shown in the above image. Let us see what are the options available in the image.

### WooCommerce Custom Product Box options

Following are the available options that could be used to define the custom product boxes.

#### Pricing Type

The plugin allows you to set up the price for the custom product with the pricing type option. Using this option you can set the price of the custom product to a **Fixed Price** or you can calculate it dynamically.

#### Box Quantity

This option allows you to set the number of items customers can add to the product.

#### Box Layout

You can customize where and how this product will be displayed along with all the constituent products in it. You can choose from Vertical layout, Horizontal layout or Vertical Right Layout for the Custom Box.

#### Columns in Gift Box

When the product will be selected on the products page or shop page, it will be visible in the form of grids. This option allows you to set the number of columns (2 or 3) you want in that grid.

#### Columns in Product Layout

Unlike the previous option, this field will let you choose the number of columns in another grid. This grid will display all the products available to create the custom product on the shop page.

#### Gift Message

You can choose to display the gift message and even set the custom message label for the custom box.

Now, if you’re done setting up the product then you can **Publish** it to make it live. The product will be visible to your customers on the products/shop page.
