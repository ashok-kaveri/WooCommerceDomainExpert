# Set up a Multi-Vendor store with WooCommerce DHL Express & Dokan

With this guide, we will explain how you can set up a Multi-vendor marketplace using the **WooCommerce Multi Vendor Shipping Addon plugin** , **WooCommerce Multi-Carrier Shipping plugin** , and **Dokan plugin**.

## WooCommerce Multi Vendor Shipping Addons Overview

The [**WooCommerce Multi Vendor Shipping Addon**](https://www.pluginhive.com/product/woocommerce-multi-vendor-shipping-addon/) transforms your WooCommerce online store into a powerful, robust, and feature-rich online shopping center.

With this addon, multiple independent vendors can sell their products via a centralized product catalog and facilitate you to ship through _**FedEx**_ or _**DHL**_. From customers’ perspectives, they can buy products from multiple vendors in a single order.

* * *

## Plugins required to set up WooCommerce DHL Express rates for multiple vendors

You must set up your WooCommerce store with the following plugins:

  1. **[WooCommerce Multi Vendor Shipping Addon](https://www.pluginhive.com/product/woocommerce-multi-vendor-shipping-addon/)**
  2. **[WooCommerce Multi-Carrier Shipping Plugin](https://www.pluginhive.com/product/multiple-carrier-shipping-plugin-woocommerce/)**
  3. **Dokan Multi Vendor plugin**

* * *

## **Installation**

  * For the WooCommerce Multi Vendor Shipping Addon, install and activate the plugin.

  * For the Dokan Multivendor plugin, refer to its documentation.
  * For the WooCommerce Multi-Carrier Shipping plugin, read __[How to Download, Install, Activate & Update WooCommerce Plugin?](https://www.pluginhive.com/knowledge-base/how-to-download-install-update-woocommerce-plugin/)

## WooCommerce Multi Vendor Addon settings

Once you have installed and activated the plugin, you can access the plugin settings in two ways:

  * Go to _Dashboard > Plugins > Installed Plugins > WooCommerce Multi Vendor Shipping Addon > Settings _(or)
  * _Dashboard > WooCommerce > Settings > WooCommerce Multi Vendor Shipping Addon._

The plugin settings are as shown in the screenshot below.

To show shipping rates on the cart page, the plugin provides the following options:

  1. **Split and sum:** Sums up the amount of all the items from the vendors and the shipping cost of each item. The total cost will be shown to the customer.
  2. **Split and separate:** Separates the items according to each vendor, and shows the total cost of shipping vendor-wise.

Click **Save Changes** after selecting the desired option.

* * *

## Adding Vendors

To set up a multi-vendor marketplace, you first need to add WordPress users and assign _**Vendor**_ user roles to them.

Creating a new WordPress user is pretty straightforward. Go to _Dashboard > Users > Add New_.

Once you have installed the _**Dokan Multivendor plugin**_ , a new user role called “ _**Vendor**_ ” will be available in the WordPress user role setting. Select this role and enter user details like name, email ID, shipping and billing addresses among other details, and save the settings.

You can create several vendor accounts in the same way. The created vendors can log in, and add products to your WooCommerce store.

## Choose the Vendor Address in the WooCommerce Multi-Carrier Shipping plugin

Go to _Dashboard > WooCommerce > Settings > Shipping > Multi Carrier Shipping_.

Once you’ve installed the plugin, you need to click on **Enable this shipping method**. After that, you need to hover down to access your DHL Express account and enter your credentials.

Next, select **Vendor Address** under the **Ship From Address Preference** to override the shipper address set in the Multi-vendor plugin settings with the _DHL Shipper Address_ specified in the Multi-Carrier Shipping plugin _,_ as shown in the screenshot below.

Remember, the above _**Multi Vendor Shipper Address**_ setting in DHL will only be available when the [_**WooCommerce**_ _**Multi Vendor Shipping Addons**_](https://www.pluginhive.com/product/woocommerce-multi-vendor-shipping-addon/) is activated.

To know more about other features of the **_WooCommerce Multi-Carrier Shipping plugin(DHL Express)_** , refer to [this article](https://www.pluginhive.com/knowledge-base/how-to-get-dhl-account-number/).
