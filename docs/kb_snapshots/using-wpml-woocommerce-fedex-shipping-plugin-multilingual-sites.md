# WPML & FedEx shipping – WooCommerce store translation

If you’re running an online store with **[WooCommerc](https://www.pluginhive.com/woocommerce-tutorial-for-novice/)** e and aiming to cater to customers from different linguistic backgrounds, you’re in the right place. Creating a seamless multilingual experience not only enhances customer satisfaction but also opens doors to new markets and increased sales opportunities.

The two essential aspects of managing a multilingual WooCommerce store are:

  * WPML
  * WooCommerce shipping plugin that supports a global shipping carrier like FedEx

WPML is a powerful plugin that allows you to easily translate and display your website content in multiple languages. It provides a user-friendly interface for managing translations, making it effortless to maintain consistency across your **[store’s various language versions](https://www.pluginhive.com/woocommerce-multilingual-plugins/)**.

Additionally, integrating FedEx shipping rates on the checkout page ensures accurate shipping calculations for customers worldwide. By leveraging the power of FedEx’s shipping rates API, you can provide real-time shipping cost estimates based on the customer’s location, weight, and dimensions of the products in their cart.

Combining the capabilities of WPML and FedEx shipping rates on the checkout page creates a seamless experience for your multilingual customers. They can browse your store in their preferred language and receive accurate shipping cost estimates based on their location, eliminating any language or shipping-related barriers.

* * *

## WPML & FedEx Shipping on the WooCommerce checkout page

To harness the power of a WooCommerce multilingual business, you need the following plugins:

  * [**WooCommerce Shipping Plugin for FedEx with Print Label**](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)
  * **[WPML plugin](https://wpml.org/)**. 

Here are the components of the WPML plugin which you need to install separately.

  * WPML Multilingual CMS
  * WPML String Translation
  * WPML Translation Management
  * WooCommerce Multilingual
  * WPML Media
  * Multilingual Tools

Once you have successfully installed the WPML plugin, you can configure it easily from **WPML >> Languages. **After that, you can follow the following steps to successfully configure the WPML plugin.

  * Select your default language.
  * Choose a set of active languages
  * Choose a language selector (For starters, choose the footer language selector; you can change this later.)
  * Install and activate all the WPML-related plugins (mentioned in the first section). If you still feel you need some help in installing the WPML plugin, you can follow this **[getting started guide](https://wpml.org/documentation/getting-started-guide/) **by WPML.
  * Install the **[WooCommerce FedEx Shipping plugin](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** and activate it.

* * *

## WooCommerce UI translation with WPML

  * **WPML Language Selector**

WPML language selector will display the list of languages that you have configured within the plugin. The plugin can automatically switch the language based on geo-location or the users can switch it manually.

* * *

  * **Easy FedEx shipping settings in the local language**

Once the language is selected the WooCommerce store settings will be translated into the selected language. **[WooCommerce FedEx Shipping](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** plugin is completely compatible with WPML and this ensures the FedEx shipping settings are also available in the preferred language using WPML translation.

* * *

  * **FedEx shipping rates on the cart page translated into French**

You can see that the FedEx official shipping service names remain the same. This happens because the shipping service name remains the same for FedEx services across the globe. However, the delivery estimates as well as the date format are translated into French.
