# Using WPML with WooCommerce Estimated Delivery Date plugin for Multilingual Sites

With this guide, we’ll show you how to set up **WPML** and **[WooCommerce Estimated Delivery Date plugin](https://www.pluginhive.com/product/estimated-delivery-date-plugin-woocommerce/)**. We’ll also show you how to display estimated delivery dates for your WooCommerce shipping methods on the Cart and Checkout pages.

## WooCommerce Estimated Delivery Dates in Multiple languages

The **[WooCommerce Estimated Delivery Date plugin](https://www.pluginhive.com/product/estimated-delivery-date-plugin-woocommerce/)** allows store owners to provide delivery estimates to their customers. The plugin provides WooCommerce store owners to set a default number of days till the delivery date and the same delivery date is reflected on the product page, cart page, and even the mini-cart widget.

The plugin also allows the store owner to predefine the holidays for both the store owner as well as the customers. With so many features, now the plugin is also compatible with the WPML plugin so that it can be used on the multilingual websites.

### Setting up a WPML Multilingual Store with Translated Estimated Delivery Dates

In order to use both the plugins together, you must install the [**WooCommerce Estimated Delivery Date**](https://www.pluginhive.com/product/estimated-delivery-date-plugin-woocommerce/) and [**WPML plugin**](https://wpml.org/) on your WooCommerce. With regards to WPML, here are the components of the that require to be installed separately.

  * WPML Multilingual CMS
  * WPML String Translation
  * WPML Translation Management
  * WooCommerce Multilingual
  * WPML Media
  * Multilingual Tools

Once you have successfully installed the WPML plugin, you can configure it easily from **WPML → Languages.** After that, you can follow the following steps to successfully configure the WPML plugin.

  * Select your default language.
  * Choose a set of active languages
  * Choose a language selector (For starters, choose the footer language selector, you can change this later.)
  * Install and activate all the WPML related plugins (mentioned in the first section). If you still feel you need some help in installing the WPML plugin, you can follow this **[getting started guide](https://wpml.org/documentation/getting-started-guide/) **by WPML.
  * Install the WooCommerce Estimated Delivery Date plugin and activate it.
