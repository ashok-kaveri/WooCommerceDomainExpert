# Does WooCommerce Canada Post Shipping Plugin Supports Different Weights for Variable Products?

When it comes to selling products online, there are a lot of variations to a single product. These variations may be based on weight, color, or any other attribute. Thanks to WooCommerce’s built-in feature that lets you define variations as Variable Products of the same product. However, the question here is not about buying and selling variable products but shipping them. According to a WooCommerce shop owner,” _**…We sell simple variations based on the color and weight of the products…As there is no issue of color when it comes to shipping, will the plugin support providing different weights to the variations or not..? Please let us know…**_ “.

In this article, we will be discussing[**WooCommerce Canada Post Shipping plugin**](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/) and how you can easily use the product variations with this plugin.

## WooCommerce Canada Post Shipping plugin

WooCommerce Canada Post Shipping plugin provides real-time shipping rates from the official Canada Post API. In other words, the plugin sends the details like the **package weight, dimensions, source and destination address, etc.** to Canada Post and gets the accurate shipping rates, which are displayed on the cart page. When it comes to product variations since there is a dedicated weight allocated to each variation, the plugin will be sending weights based on the variation added to the cart. And hence, the shipping rates will be shown for that variation only.

In case, you want to see which weight and dimensions are being sent to Canada Post by the plugin, you can turn on the **Debug Mode** , and check the **Canada Post Request.** You will be able to see the weight and dimensions of the product variation that the customer has added to the cart.
