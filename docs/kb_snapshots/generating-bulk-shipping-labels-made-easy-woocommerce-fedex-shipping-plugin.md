### Printing multiple FedEx shipping labels in WooCommerce

Once the plugin is installed and activated, all you have to do is change the image type of the shipping label to _**png.**_ This is because the plugin only supports bulk label generation in the PNG file format only.

You can find the option to change the image type in the plugin settings under the **Label Generation** tab. The image below shows the option under the Label Generation tab.

* * *

Once you change the image type and save the settings, all you have to do is wait for the customers to place orders. The following image shows the orders placed on the orders page.

* * *

Once you have all the orders, just select all the orders for which you want to create the shipping labels. And after that, select the option to create FedEx shipping labels, under Bulk Actions. The following image will show you the option under Bulk Action.

* * *

Then click on apply, and the plugin will generate official FedEx shipping labels for all of the orders that you have selected. The following message will appear once the shipping labels are successfully created.

* * *

### Downloading Shipping Labels for WooCommerce Orders in Bulk

Well, the **[WooCommerce Shipping plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/) **not only helps in generating the shipping label but it also helps the store owners to download the shipping labels in bulk. This way the store owners can make use of the shipping label and fulfill their orders.

Once you have successfully generated the shipping label, you need to select all the orders you want to get shipping labels and choose the option to print shipping labels from Bulk Actions.
