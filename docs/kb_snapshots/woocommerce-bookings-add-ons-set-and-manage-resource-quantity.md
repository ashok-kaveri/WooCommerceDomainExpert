# Bookings and Appointments for WooCommerce Add-ons – Set and manage resource quantity

The Bookings and Appointments for WooCommerce plugin allows customers to select resources or extra add-ons when placing a booking using the Booking Resources feature. However, this feature is suitable for booking addons that do not require customers to enter the quantity of resources/addons during booking.

If you require your customers to choose the number of resources they want to book as well as manage the resource quantity from the WooCommerce admin page, you can check out the **WooCommerce Resource Quantity addon** for the Bookings and Appointments for WooCommerce plugin.

Using the WooCommerce Resource Quantity addon, you can allow customers to choose the quantity of a single resource and also maintain its availability.

* * *

**_Note_**  
* The addon can only be used for a single resource.   
* The addon requires the Booking Participant option to be enabled.  

* * *
