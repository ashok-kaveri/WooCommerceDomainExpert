# Add FedEx WooCommerce Tracking Number to Order Completion Email

With this tutorial, we’ll show you how to add the WooCommerce Tracking Number for your FedEx Shipments in the order completion email using the **[WooCommerce Shipping Plugin for FedEx with Print Label](https://www.pluginhive.com/knowledge-base/box-packing-calculation-shipping-rates-based-weights-dimensions/)**.

* * *

## The need to add WooCommerce tracking number in the order completion email

WooCommerce lets you sell products online with ease. However, when you’re required to ship products to your customers, you would require some additional help.

For instance, to attach the shipment tracking number to the order completion email, you will have to do it manually. This is not recommended since it’s not a vaible solution, especially for a longer run.

The **[WooCommerce FedEx Shipping Plugin](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** comes out as the best option for WooCommerce users who need to ship items using FedEx shipping services.

This plugin automatically adds the WooCommerce tracking number to the emails so your customers could track their shipments in real-life. Let’s take a real-life example and try to understand how this works.

**Customer:**

_In addition to tracking email generated from FedEx, I want to include the FedEx tracking number in the “completed order” email sent from my website. Could you please tell me how do I achieve this with the WooCommerce FedEx Shipping plugin?_

* * *

## Solution using the WooCommerce FedEx Shipping Plugin

The **[WooCommerce Shipping Plugin for FedEx with Print Label](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** automatically attaches the order/shipment tracking information to the order completion email.

Let’s see how this plugin enables you to do that.

Once the order is placed, move to the **_WooCommerce > Orders _**page. You would see the entire list of orders on the site. A sample screenshot is shown below:
