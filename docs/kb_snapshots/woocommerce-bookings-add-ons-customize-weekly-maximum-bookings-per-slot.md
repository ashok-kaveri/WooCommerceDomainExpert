# WooCommerce Bookings Add-ons – Customize Maximum Bookings Per Slot for All Week

The Customize Maximum Bookings per slot add-on gives store owners additional flexibility to specify the number of bookings they want to accept for different slots based on criteria. This add-on allows you to set up maximum bookings that can be placed for a single block based on a custom date range, range of months, and range of days.

**Customize Maximum Bookings Per Slot for All Week add-on** allows you to set up maximum bookings that can be placed for a single block based on Time range (all week).

* * *

**_Note_**  
This addon can only be used alongside the **[Customize Maximum Bookings per slot addon.](https://www.pluginhive.com/knowledge-base/woocommerce-bookings-add-ons-customise-maximum-bookings-per-slot/)**  

* * *

### Pre-Requisites

  * [Bookings And Appointments for WooCommerce](https://www.pluginhive.com/product/woocommerce-booking-and-appointments/)**[Version 2.0.6 and above]**
  * Customize Maximum Bookings Per Slot for All Week addon
  * **[Customize Maximum Bookings Per slot addon](https://www.pluginhive.com/knowledge-base/woocommerce-bookings-add-ons-customise-maximum-bookings-per-slot/)**

### What does it do?

This add-on**** allows you to set up maximum bookings that can be placed for a single block based on Time range (all week)

### How to set it up?

  1. Contact our **[support team](https://www.pluginhive.com/support/)** to download the **Customise Maximum Bookings Per Slot for All Week** add-on in your WooCommerce store
  2. Setup the add-on rules by providing the following details

  * **Product Name****  
**Here you can select the bookable products for which you want to set up maximum bookings for a slot
  * **Time Range type****  
**Time Range (all week)
  * **From & To****  
**Set the From and To bookings time range
  * **Maximum Bookings Count****  
**Set the maximum bookings that will be acceptable for the product
