# Universal Shipping Calculator for La Poste Colissimo on WooCommerce

In this small guide, we will explain to you how you can migrate your La Poste Colissimo account to the Universal Shipping Calculator using the **[WooCommerce Table Rate Shipping Plugin](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/)**.

## How to Set Up La Poste Colissimo Shipping on Your WooCommerce Store?

To set up La Poste Colissimo shipping, follow the steps:

  1. Download the **[WooCommerce Table Rate Shipping Pro Plugin](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/)** and CSV file(data file) for La Poste Colissimo from My Account.
  2. Install WooCommerce Shipping Pro Plugin. For detailed installation information, see __**[How to Download, Install, Activate& Update WooCommerce Plugin?](https://www.pluginhive.com/knowledge-base/how-to-download-install-update-woocommerce-plugin/)**
  3. The Admin Configuration Settings appear as shown below:

Admin Configuration Settings

Import the CSV file by clicking on the Import CSV button (highlighted in the above screenshot). The screen appears as shown below:

Import Rate Matrix
* Browse the CSV file(which you have downloaded from MY Account) by clicking on Choose File or enter the path of data file. Click Upload file support. The Success Message appears as shown below:  

The Rate Matrix is imported into Admin Settings as shown below:

Colissimo Rate Matrix

Please note that only if the WooCommerce Table Rate Shipping plugin is enabled, you will see La Poste Colissimo shipping rates on the cart/checkout page of your WooCommerce store.
