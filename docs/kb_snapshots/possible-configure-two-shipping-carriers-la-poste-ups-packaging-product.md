# Is it possible to Configure Two Shipping Carriers, La Poste and UPS, for each Packaging and Product?

In this article, we will cover how Steve can set up [**WooCommerce Table Rate Shipping Pro**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) plugin to calculate shipping based on product quantity. So read along to know more about it.

WooCommerce store owners have had a preference for customized shipping rates over real-time shipping rates from various carriers. Especially when dealing with multiple types of products, store owners seem to get confused by the shipping rates provided by the shipping carriers.

According to Steve, a WooCommerce store owner, “ _**…We are champagne producers and sell bottles of different sizes. It includes classic, half-bottles, Magnum, Jeroboam, mathusalem. Bottles and half-bottles are sold by 6 or 12 or 18 or 24. Magnums by 1 or 4 or 8 and Jeroboam and Methuselah only by 1.I have 2 carriers with fixed price Per package AND per quantity. Can I set up shipping rates using WooCommerce Table Rate Shipping Pro plugin..?** _“

## Setting Up Shipping Classes

Since Steve is dealing with multiple types of bottles, it would be best to create separate shipping classes for each one of them. Steve can create shipping classes for,

  * **Classic**
  * **Half Bottle**
  * **Magnum**
  * **Jeroboam**
  * **Methuselah**

* * *

## Configure WooCommerce Table Rate Shipping Pro

Now Steve can easily create shipping rules based on the shipping classes. For this, he needs to select the following **Matrix Columns** from the Settings tab in plugin settings.

  * **Method Title**
  * **Method Group**
  * **Shipping Class**
  * **Item**
  * **Rates Based On**
  * **Base Cost**

Once he selects these columns, he can set the calculation mode to**Per Shipping Class**. After setting up these, he can easily configure shipping rules based on his requirements. The image below shows Steve’s shipping rules configured using the WooCommerce Table Rate Shipping Pro plugin.
