# Integrate FedEx Shipping Calculator with WooCommerce website

Here’s an article that’ll help you successfully integrate the **[FedEx Shipping calculator](https://www.pluginhive.com/determine-fedex-shipping-estimate-for-your-woocommerce/)** on your website. You can show the real-time FedEx shipping rates using the **[WooCommerce Shipping plugin for FedEx with Print Label](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**. So read along to know how to do it.

**Customer:**

I want to integrate the WooCommerce Shipping calculator for FedEx on my website. How should I go about it?

* * *

**PluginHive Support:**

Integrating the FedEx shipping plugin with WooCommerce is easy.

It can be done in three easy steps:  
1\. Install the plugin.  
2\. Configure the settings of the plugin  
3\. Check the rates (troubleshoot the transaction if the rates are not coming correctly).

We suggest you go kindly through our **[setting up FedEx documentation](https://www.pluginhive.com/knowledge-base/setting-woocommerce-fedex-shipping-plugin/)** so that you get a holistic understanding of the integration.

For more information on debugging, kindly go through our **[Troubleshooting guide](https://www.pluginhive.com/knowledge-base/troubleshooting-woocommerce-fedex-shipping-plugin/)**. If the problem still persists, kindly provide us request and response in a text file.
