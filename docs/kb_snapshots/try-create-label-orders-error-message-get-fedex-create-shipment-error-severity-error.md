## When do you get this error?

This error occurs if your address and country do not match. And since this plugin interacts with FedEx APIs to generate shipping labels. So if you send a wrong shipment generation request then the Woocommerce FedEx Shipping plugin won’t be able to provide you with a valid shipping label.
