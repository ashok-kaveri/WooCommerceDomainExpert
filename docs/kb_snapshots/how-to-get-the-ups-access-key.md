# How to get the UPS Access Key?

The WooCommerce UPS Shipping Plugin with Print Label requires you to have the UPS Access key in order to make it work. Check out this guide that helps you find the key.

**Customer** :

Can you explain to me what the Access Key is for setting up the account? I do have a UPS.com account, but I don’t have an access key.

[](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)

**Support** :

1) An Access Key provides your business access to UPS systems, which hold the information you or your customers need to ship, track or rate a package. It is an essential component of our UPS plugin to work correctly.

Kindly go through the following steps for getting the Access key:

  1. Sign up with [UPS.com](http://www.ups.com/) to get Account details.
  2. Register with My UPS.
  3. Log-in with your UPS credentials.
  4. Request for an access key.
