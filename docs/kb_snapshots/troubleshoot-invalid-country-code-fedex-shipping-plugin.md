# Fix “Invalid Country Code” Error with WooCommerce FedEx Plugin

In this article, we will show you how to troubleshoot the invalid country code error when using the **[WooCommerce Shipping Plugin for FedEx with Print Label](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**. Read along to know more.

### When do you get the Invalid Country Code error?

The **[installation process for](https://www.pluginhive.com/knowledge-base/setting-woocommerce-fedex-shipping-plugin/)[WooCommerce Shipping Plugin for FedEx with Print Label](https://www.pluginhive.com/knowledge-base/setting-woocommerce-fedex-shipping-plugin/)** is quite simple. However, there are times when users make a few mistakes and as a result, they see certain errors. These errors may be unsettling for some users who just bought the plugin. But don’t worry, we will tell you how to fix them.

One of the most common mistakes users do is they enter the country code incorrectly while setting up **[WooCommerce Shipping Plugin for FedEx with Print Label](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**. As a result, they don’t see the FedEx shipping rates on the Cart page even if they enter a correct address.

#### **A real-life example of Invalid Country Code error**

As you’d imagine, users who don’t know the correct process would often see this issue. Let us take an example of one of our customers who faced a similar issue in the past.

> Taylor: I am trying to get the FedEx shipping rates to show up for products and it’s not showing up. I tried to enable them in “Shipping Zones”. I also cannot get it to show up on the checkout page. It’s saying there’s No Shipping Method Available.

Taylor here was not able to figure out the actual problem as to why she’s not able to see the **[FedEx shipping services](https://www.pluginhive.com/knowledge-base/choosing-woocommerce-fedex-shipping-method/)** on the Cart page. And hence, she reached out to us for help.

After a round of discussion, we came to know she had not entered the correct country code in the shipping address section in the plugin. Since her store is located in the U.S., she had entered the country code as the**‘USA’** , which is not her problem. But FedEx only takes in country code in 2 Digit format instead of the much widely-used code **‘USA’.** You can visit FedEx’s official guide to find **[2 digit country codes for different countries](http://www.fedex.com/mp/tracking/codes.html)**.

As a solution, we told her to enter **‘US’** instead of **‘USA’**. After which she was able to get the FedEx shipping rates on the Cart page and perform other actions like print FedEx shipping labels and providing FedEx shipment tracking.

## **Bonus tip: Choosing ‘Ship From’ address in your WooCommerce**

Another common mistake new users make is when they have to choose between the Origin Address and the Shipping Address.

The **Origin Address** is the Shipping address that you would have mentioned while setting up the plugin.

**Shipping Address** , on the other hand, is your customer’s destination where you wish to ship your shipments.
