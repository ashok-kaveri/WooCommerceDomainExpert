# Calculate Price Based and Per Item Shipping Rates using WooCommerce Table Rate Shipping Pro

In this article, we will be discussing [**WooCommerce Table Rate Shipping Pro**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) and how using this plugin you can easily set up shipping per item as well as you can calculate shipping rates based on the total price.

WooCommerce store owners may choose shipping rates based on some factors instead of going for the real-time shipping rates from shipping carriers. This way they can have more control over the shipping rates and based on what the shipping rates are changing. However, personalizing the shipping rate calculation is not an easy task.

According to Janett, “ _**My client wants to have 1 product (which is heavy) to have its own shipping cost (1 for UK, 1 for Europe, 1 for Rest Of World) – this needs to be per item (per stool) and be added to any other shipping costs if other products are also bought… I really hope this is making sense…Is there any way I can provide shipping rates per item when I have my rates set up based on the price..?? Please help. Thanks..!**_ “

* * *

## Selecting Matrix Columns

Since Janet’s request consists of multiple factors for which she needs to calculate shipping for, she needs to select matrix columns based on that only. For that one product, she can create a separate shipping class to make the calculations very easy. In this case, we require the following Matrix Columns.

  * **Method Title**
  * **Method Group**
  * **Zone List**
  * **Shipping Class**
  * **Item**
  * **Price**
  * **Rate Based On**
  * **Base Cost**
  * **Cost per Unit**
