# WooCommerce Bookings Availability Search Widget

With this guide, we will cover one of the widely used functionalities in online bookings, i.e, the Availability Search.

The **Bookings Availability Search** feature lets customers perform a quick search based on their preferred date and see all the available bookings between the date.

Read along and see how to provide the same functionality on your WooCommerce store with the help of the **Availability Search Widget** using [Bookings and Appointments for WooCommerce](https://www.pluginhive.com/product/woocommerce-booking-and-appointments/).

## What is WooCommerce Bookings Availability Search Widget?

The Availability Search feature introduces a widget on your website that customers can use to search for a suitable booking within a specific date range.

This feature allows customers to enter the ‘from’ and ‘to’ dates and search for all the available bookings for that range. The plugin then lists all available bookings to make it convenient for the customers to find what they are looking for.

**Note: The Widget will be displayed only on the Website Home Page and Shop Page**

## How to Set up the Search Widget with the Bookings and Appointments for WooCommerce plugin?

The Availability Search Widget is a perfect tool for hotel room bookings where you offer different types of rooms. As you know, it’s a rather tiring task to check for the availability of each room based on your preferred date.

Besides, if customers can’t find what they are looking for within a couple of searches, there is a high chance that they will end up looking somewhere else.

The Availability Search Widget is an intuitive way to find the desired room. All they need to do is search for the dates, and the plugin will display only those rooms which are available on that date.

Let’s consider a business case to understand how this works.

**Allow customers to rent a room that is available throughout a particular week(7 days).**

_**Customer:** I provide rooms on rent and most of the time our rooms are booked. We need a mechanism where the customers can just enter the dates they want to book a room. Based on the dates, they can see all the available products that they can book._

### Solution using the Bookings and Appointments for WooCommerce plugin

Follow the steps below to set up a hotel room rental based on the scenario above.

  * Install the [**Availability Search Widget**](https://www.pluginhive.com/tailor-made-woocommerce-bookings-solutions/#availability_search_widget) addon ([contact us to get a custom quote](https://www.pluginhive.com/support/))
  * Visit the **Appearance = > Widgets** to enable the widget and add it to the website
  * Click on the **Booking Search** widget and choose where you want to place the widget

  * Click on **Add Widget**
  * Enter the name that you want to display for the widget, for example,**Check Booking Availability** , and click on **Done**
