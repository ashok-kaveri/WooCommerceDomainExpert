# Recover Postage Expenses by including the UK Postal-Code Surcharges to your Shipping Rates using WooCommerce Table Rate Shipping Pro

In this article, we will be covering [**WooCommerce Table Rate Shipping Pro** ](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/)and how using this plugin WooCommerce store owners can easily add additional surcharges to their shipping rates based on postcodes.

WooCommerce store owners ship to multiple areas throughout the world. However, in some places, the shipping charges include various taxes and additional surcharges based on various factors. In such cases, the store owners must have some mechanism to recover the extra surcharges. According to Amy, a WooCommerce store owner, “ _**…Hello, we are only using one main price. So:**_

_**1) There are 4 sizes with a rate for each**_  
 _**2) There is a flat rate for each additional item**_  
 _**3) There are postcode surcharges for some areas.**_  
_**Is there any way I can add the postcode surcharge to the shipping cost..? Thanks.”**_

## Adding Postcode based Surcharges on Shipping Rates

WooCommerce Tabel Rate Shipping Pro plugin provides store owners with a mechanism to calculate shipping rates based on various factors such as weight, price, quantity, shipping location, etc. It uses the Matrix Columns to define the parameters based on which the shipping rules will be created. So if the store owners require adding the extra charges based on postal code, they can easily do so by selecting the **ZIP code** in the matrix columns in the settings tabs of plugin settings.

Once they have done this, they can create shipping rules based on the zip code they want to add extra charges. Their shipping rules will be something similar to the shipping rules in the image below.
