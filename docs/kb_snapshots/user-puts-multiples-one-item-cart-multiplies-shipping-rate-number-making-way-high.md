# Can I pack multiple units of the same product together with WooCommerce UPS Shipping Plugin?

In this small guide, we will tell you if you can pack multiple units of the same product together when using the **[WooCommerce UPS Shipping Plugin with Print Label](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)** or not. Read more below.

**Customer** :

If a user puts multiples of one item in the cart it multiplies the shipping rate by that number, making it way too high. However, if you have several different items in the cart the rate is correct. I’m using the Basic version. Is this a limitation of that version? Does it work correctly in the Paid/Premium version?

* * *

**PluginHive Support** :

The basic version of the plugin is meant for small business owner or when you have one item in the order as it packs every item individually. That’s the reason you are finding high rates for multiple items.

However, on our premium version, we have options for [**box packing and weight-based packing**](https://www.pluginhive.com/knowledge-base/fedex-woocommerce-shipping-plugin-pack-items-boxes/) that allow you to pack multiple items together.
