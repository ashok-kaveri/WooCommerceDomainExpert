# What are the default units of weight, dimensions, and price for Shipping Pro?

In this article, we will tell you what are the default units of weights, dimensions, and price options available when using the WooCommerce Table Rate Shipping Pro Plugin. Read below to know more about it.

The WooCommerce Table Rate Shipping Pro does not have any units of measurement. It only takes the units defined at the Woocommerce Plugin Settings Level. For instance, we can see some rules framed in the Shipping Pro Plugin.

* * *

* * *

Min-Max (weight) – The value for the method “up to 2.5 kg” varies from 0 to 2.5 kg

  * The value for the method “over 2.5 kg” varies from 2.5 to 99 kg
  * The value for the method “over $50 Free” varies from 0 to 99 kg

Min-Max (price) – The value of the method “over $50 Free” varies from $50 to $99  
We inferred these units from the Woocommerce Settings Level as shown below:
