# Fix the error message “There are no valid services available” for FedEx Mexico

Does FedEx support packages like FedEx Box, FedEx Pack, FedEx Tube, etc., in Mexico when using the **[WooCommerce Shipping Plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**? Find it out in this small guide.

**Customer:**

I am getting an error message displayed as “There are no valid services available”. My business is based in Mexico.

* * *

**PluginHive Support:**

In the WooCommerce Shipping plugin for FedEx settings of your website, packaging type is selected as default. But for Mexico, FedEx doesn’t support packages like FEDEX_BOX, FEDEX_PACK, FEDEX_TUBE.

We recommend you to select package types like FEDEX_10KG_BOX, FEDEX_25KG_BOX or FEDEX_ENVELOPE.  
Else, you can disable all predefined boxes and add your own box under ‘Box Sizes’ section.

If you need any help setting up FedEx shipping on your WooCommerce store, feel free to **[Contact PluginHive Customer Support](https://www.pluginhive.com/support/)**. We would be more than happy to help.

_Good luck!_
