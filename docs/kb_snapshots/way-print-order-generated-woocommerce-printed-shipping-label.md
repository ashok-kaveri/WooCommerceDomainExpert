# Print Order number on the WooCommerce Shipping Label

With this guide, we’ll show you how to print order number on the WooCommerce shipping label for popular shipping carriers like FedEx, UPS, and Canada Post.

## Why is it important to print order number on the WooCommerce shipping label?

Apart from the shipping the actual package itself, a shipping label provides a lot of information. It’s a necessary element required by shipping carriers like UPS, FedEx, and Canada Post to deliver shipments to the correct addresses, fast.

For you, a store owner, shipping label plays a really important role. It’s the only physical thing that connects your WooCommerce orders to its corresponding packages. So clearly, by printing the **Order Id** on the labels would help you assign labels to the correct shipments. This is especially helpful when you have 10s or 100s orders to deliver at a time.

Printing the WooCommerce order numbers on the shipping labels is also helpful for accounting purposes. You could maintain the perfect record of your orders, shipments, and the corresponding earnings.

Let’s take a real business case and see how to print the order numbers on the shipping labels.

**Customer:** “Is there any way to print order number generated by WooCommerce on the FedEx shipping label? We allow customers to do multiple shipping addresses in the same order, and it would help a lot to be able to group them via order number when we print shipping labels”.

* * *

## How to print WooCommerce order numbers on the shipping labels generated by different shipping carriers?

WooCommerce, as you may know, doesn’t let you to print shipping labels right from the website. However, you do have some carrier-specific **[WooCommerce shipping plugins](https://www.pluginhive.com/product-category/woocommerce-plugin/woocommerce-shipping/)** that allow you to create shipments and print labels for them.

As an example, we’ll take three popular shipping carriers(**UPS** , **FedEx** , and **Canada Post**) and show you the necessary steps required to do that.

* * *

### Printing WooCommerce order numbers on UPS Shipping labels

With the help of **[WooCommerce UPS Shipping plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)** , users can create shipments and print the shipping labels for them right from their website. But to print order numbers on the labels, users must enable the **Include Order Id in Shipment Description** option found on the plugin settings page.

Once you do that, you should be able to print the UPS shipping labels with the corresponding Order number. Here’s a sample label that contains the order number at the bottom of the label represented by **Reference No.**.

* * *

### Printing WooCommerce order numbers on FedEx Shipping labels

When it comes to FedEx, the **[WooCommerce FedEx Shipping plugin](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** is the ideal choice because of the label generation feature that it offers. With its seamless integration with WooCommerce, this plugin would let you automatically print the order numbers on the shipping labels.

So you don’t have to enable any option or set up anything in the plugin settings page. Here’s a sample FedEx shipping label for you to check. As you can see, the order number is represented by **REF:**

* * *

### Printing WooCommerce order numbers on Canada Post Shipping labels

Finally, the **[WooCommerce Canada Post Shipping plugin](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/)** is the best choice for WooCommerce users looking to set up Canada Post shipping on their website. Also, this plugin is the only officially certified Canada Post plugin that allows users to print shipping labels.

Similar to the FedEx shipping plugin above, the WooCommerce Canada Post Shipping plugin also prints the order numbers on the shipping labels automatically. The order number is represented by the **Ref.** and can be found at the bottom part of the Canada Post shipping label. Have a look at the image below.
