# Set up WooCommerce Table Rate Shipping with Divi Theme

With this article, we’ll show you how to successfully set up table rate shipping on your Divi theme WooCommerce store using the [**WooCommerce Table Rate plugin**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/).

You will notice how well the Divi theme shows the WooCommerce Table Rate Shipping plugin’s personalized shipping rates on WooCommerce Cart and Checkout pages.

Online store owners are huge fans of website theme customization. They can be often seen requesting custom features for their websites. One of the biggest examples of this is the availability of tons of WordPress themes.

WordPress themes provide users with the ability to customize the overall website look and feel. One such theme is the **Divi Theme** that offers a lot of customizations for the store owners.

## WooCommerce Table Rate Shipping Pro plugin

The **[WooCommerce Table Rate Shipping Pro plugin](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/)** is one of the best WooCommerce shipping plugins available our there. Using this plugin, store owners can personalize shipping rates based on the following parameters.

  * **Product Weight**
  * **Product Quantity**
  * **Cart Total Value**
  * **Destination Address (Shipping Zone, Country, City, State, ZIP Code)**
  * **Product Category**
  * **Shipping Class**
  * **Shipping Zone**

Besides this, the plugin also has some advanced features like,

  * **Ability to choose Minimum/Maximum shipping cost**
  * **Calculate shipping rates for a combination of multiple shipping classes or categories**
  * **Calculation Modes (per order, item, shipping class, and per line item)**

All the above-mentioned features give the WooCommerce Table Rate Shipping Pro plugin the ability to configure almost any shipping scenario.

Now let’s see how this plugin works with Divi theme WooCommerce and offers an exceptional online shopping experience.

## WooCommerce Custom Cart Widget

Apart from the coolest feature of the theme, the Visual Builder, there are a ton of cool things you can do on your website using this theme. One such feature is to select amongst the pre-installed widgets.

The best widget that we feel could help customers a lot, is the **Cart Widget.** This widget displays all the contents of the cart at the top-right corner of the website.

It has one amazing application. Since this widget is visible to customers even while they are looking at other products, they can always check what items are currently in their cart with just a glance.

Divi theme provides an option to disable the cart widget until there is a product in the cart. In other words, the cart will be visible once you start adding products into the cart.

## WooCommerce Cart page

**[WooCommerce Table Rate Shipping Pro](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/)** allows store owners to calculate shipping rates and display them on the cart page based on the conditions of product weight, quantity, price, etc., So it’s mandatory that the shipping rates are visible clearly on the cart page.

One common issue found in most themes is when displaying shipping rates on the cart page. Usually, the shipping methods and prices are shown with no proper alignment.

In the image below, you can see the cart page where the shipping rates are perfectly aligned and visible to the customer. This is because the Divi theme is compatible with the WooCommerce Table Rate Shipping Pro plugin.

## WooCommerce Checkout Page
