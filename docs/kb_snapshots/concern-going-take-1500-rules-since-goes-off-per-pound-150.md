# My concern is that it’s going to take 1,500 rules since it goes off per pound up to 150#

In this small guide, we will tell you how you can import a huge list of different shipping rules onto your WooCommerce Table Rate Shipping Pro Plugin using a CSV file. This solution should help you save up a lot of time.

**Customer:**  
I have a client that uses a different shipping table, and I was wondering if it would work fine with your plugin. There are ten different zones and the price changes per pound. There’s no algorithm, so I guess I would just have to create a rule for each weight. My concern is that it’s going to take 1,500 rules since it goes off per pound up to 150#. Is that going to be too much for the plugin to handle? I’ll attach a screenshot of the rates in case I didn’t explain it right. Maybe there’s an easier way to enter the data. I’m new to table rates within WooCommerce.

* * *

**Support:**  
The plugin can easily handle 1500 rules or more.  
However, the only minor issue that can arise is the PHP post limit. There is a limit to the amount of data that can be added to a single page. However, this shortcoming can be easily overcome by creating the rules in a CSV file and then importing that CSV using the “Import CSV” command.

Unfortunately, we could not trace any trends in the data that would allow you to frame rules in a more efficient manner.
