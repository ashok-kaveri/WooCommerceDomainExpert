# Fixing Ä, Ö, Ü & ß on UPS Shipping Labels in WooCommerce

[**UPS**](https://www.pluginhive.com/ups-shipping/) is one of the most trusted brands when it comes to shipping carriers. With tons of shipping services for both domestic and international shipping, it serves the purpose well. Even while handling WooCommerce shipping, the WooCommerce UPS Shipping plugin is also one of the best shipping plugins. However, sometimes while handling shipping in some countries, WooCommerce store owners can face some issues.

According to Sam, a WooCommerce store owner, “** _…I have faced this problem with a lot of plugins. As soon as I generate a UPS label, Ä, Ö, Ü, and ß appear on the label as a special type. Is there any way to correct this?_** “

In this article, we will be discussing the[**WooCommerce UPS Shipping plugin**](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/) and the shipping label printing using this plugin.

* * *

## Handling the Special Characters

**[WooCommerce UPS Shipping plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)** allows store owners to handle special characters that are printed on the shipping label. In fact, the plugin has a dedicated option that allows characters like**Ä, Ö, Ü, and ß** , to appear as they are intended. By enabling the Enable Latin Encoding option in the plugin settings, WooCommerce store owners like Sam can get rid of this issue very easily.
