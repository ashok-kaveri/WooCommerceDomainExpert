# WPML Compatibility with WooCommerce Shipment Tracking Pro

We have some good news! PluginHive has been working with the WPML Team regarding the compatibility of **[WooCommerce Shipment Tracking Pro plugin](https://www.pluginhive.com/product/woocommerce-shipment-tracking-pro/)** with the WPML multilingual plugin.

* * *

## How does the WPML integration help PluginHive users?

This new integration will enable you to expand your business globally. It provides your customers with the shipment tracking details of their orders without worrying about language translations.

It has been a great pleasure working with the WPML team to test the plugin’s compatibility to ensure that the **WooCommerce Shipment Tracking Pro Plugin** works flawlessly with WPML.

* * *

### Why use WPML?

WPML has been the industry standard for more than 500,000 websites when it comes to multi-lingual translations for plugins, themes, theme options, blog posts, etc. on WordPress. Using this WooCommerce Multi Lingual plugin you can provide a comprehensive translation of your store to customers worldwide.

In order to make your website multi-lingual so that even the WooCommerce Shipment Tracking Pro plugin can work in multiple languages, you would need to purchase the**[WPML Plugin](https://wpml.org/purchase).**

* * *

### Why use WooCommerce Shipment Tracking Pro?

On the other hand, the WooCommerce Shipment Tracking Pro plugin by Pluginhive is one of the best [**WooCommerce order tracking plugins**](https://www.pluginhive.com/knowledge-base/top-5-paid-woocommerce-shipment-tracking-plugins/). It provides some of the best in class features like 85+ shipping carriers preconfigured, automatic scheduling of tracking data import via FTP, handling bulk tracking details via CSV import, etc.,

You can check out the [**WPML compatibility page**](https://wpml.org/plugin/woocommerce-shipping-tracking-pro/) for our plugin and also read the documentation: **[WPML compatibility for WooCommerce Shipment Tracking Pro Plugin](https://www.pluginhive.com/knowledge-base/using-wpml-woocommerce-shipment-tracking-pro-plugin-multilingual-sites/)**.

If you need any help setting up shipment tracking on your WooCommerce store, feel free to **[Contact PluginHive Customer Support](https://www.pluginhive.com/support/)**. We would be more than happy to help.

_Good luck!_
