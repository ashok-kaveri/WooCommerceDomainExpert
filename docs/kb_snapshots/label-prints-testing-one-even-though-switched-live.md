# The only label that prints are a testing one even though I have switched to live

**Customer** :

We are unable to print labels in our orders. The only label that prints are a testing one even though I have switched to live. We do not have a contract with [**Canada Post**](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/) but do have an account. How can I get someone to take a look at my settings?

* * *

**Support** :

Kindly check your Canada Post Credentials.

**– If you are using test credentials, then kindly uncheck the “Production Key”.**  
–**If you are using live credentials, then kindly check the “Production Key”.**  
This should solve the problem.

* * *

**Customer** :

Where do I find these Production Keys?

* * *

**Support** :

We have an option called API mode in the plugin settings.

If you are using the test credentials, you should select the API mode as the test.

If you are using the production credentials ( test credentials). you should select the API mode as life.
