# Configure FedEx International Shipping with WooCommerce

**Customer:**

International shipping rates are not showing up on our website. Our shipping app has international shipping prices for the package I want to ship, but FedEx international shipping is not available as shipping options on our site.

* * *

**PluginHive Support:**

We hope you were successful in setting up the **[WooCommerce Shipping Plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**. For any help on the setup of the plugin, you can refer the article on **[Troubleshooting WooCommerce shipping plugin for FedEx](https://www.pluginhive.com/knowledge-base/troubleshooting-woocommerce-fedex-shipping-plugin/)**.

After following the above steps, if you still have any problem with the shipping services or rates, kindly follow below steps:

  1. Make sure that the international shipping services are enabled in the plugin settings.
  2. Enable the debug option from the settings tab and try debugging the transaction by analyzing the request and response.
  3. To compare the services with the services returned from FedEx, kindly go to [FedEx Rate Calculator](https://www.fedex.com/ratefinder/home).

If the problem still persists, kindly provide us the following details:

  * Screenshot of FedEx calculator.
  * Request and response in a text file.

Check out the **[WooCommerce Shipping Plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** product page for more features and shipping options.
