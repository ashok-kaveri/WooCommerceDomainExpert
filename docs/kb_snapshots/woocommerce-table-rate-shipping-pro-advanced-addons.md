### WooCommerce Shipping Discounts based on Cart Subtotal

#### What does this plugin do?

The Shipping Discount based on the Cart Subtotal Add-on plugin will allow you to set up dedicated rules to provide a shipping discount. The plugin will provide a percentage discount on the shipping rates calculated by the WooCommerce Table Rate Shipping Pro plugin, based on the cart subtotal.  

#### Pre-Requisites

In order to make use of this add-on, you would require the following,

  * [**WooCommerce Table Rate Shipping Pro plugin**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) **[v – 3.1.3 and above]**
  * **WooCommerce Shipping Discounts based on Cart Subtotal [contact PluginHive Support]**

#### Business Case

 _I want to provide a certain discount on the shipping method. But only discount on the shipping charge, not cart subtotal._

_For example: If a customer purchases 3 products,_

_**Item A = $10**_  
 _**Item B = $20**_  
 _**Item C = $10**_

 _**Cart Subtotal = $40**_

 _**Shipping Charge = $10**_

 _**Cart Total = $50**_

 _The system should be able to calculate the discount in such a way that if a customer has purchased $30 or over, he should be entitled to a 30% discount on shipping rates._

_**Shipping Charge = $10 – (30% of $10)**_

_**New Cart Subtotal = $40 + $7 = $47**_

 _The system should be able to calculate the shipping discount similarly for, let’s say if the customer purchases $50 worth of goods and so on._  

#### Solution using the plugin

Follow the steps below to set up a Shipping Discount based on the Cart Subtotal.

  * Download the **WooCommerce Shipping Discount Based on Cart Add-on.**
  * Install the Add-on on your WooCommerce store and click on plugin settings

  * Click on **Add** to add a new rule where you can provide the following details
    * **Shipping Rule**  
This field will display the available shipping method name that you have set up in the WooCommerce Table Rate Shipping Pro plugin
    * **Price Range**  
This field will include the Cart Subtotal Price Range for which you want to set up discount rules. You can enter the following under this field
      * **Min Price**
      * **Max Price**
    * **Discount (%)**  
Enter the discount percentage which you need to provide on the shipping rates

  * Click on **Save** Settings

### WooCommerce Cart Total Weight Adjustment

#### What does this plugin do?

The WooCommerce Cart Total Weight Adjustment Add-on plugin extends the functionality of the WooCommerce Table Rate Shipping Pro plugin by allowing you to adjust the cart’s total weight.

Using this add-on, you can set weight adjustment rules based on the cart’s total weight. You can just define a weight range in the plugin settings and provide the additional weight which will be added to the cart’s total weight.

#### Pre-Requisites

In order to make use of this add-on, you would require the following,

  * [**WooCommerce Table Rate Shipping Pro plugin**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) **[v – 3.1.3 and above]**
  * **WooCommerce Cart Total Weight Adjustment [contact PluginHive Support]**

#### Business Case

 _I require a function to be able to calculate and add additional weight to net product weight._

_For example:_

  * _If the Net weight is_
    * **_Up to 500g then add 180g of package material_**
    * **_Up to 1kg then add 250g of package material_**
    * **_Up to 1.5kg then add 320g of package material_**
  * _Then Shipping Rules must be_
    * **_Shipping Rates for products weighing up to 500g = $20_**
    * **_Shipping Rates for products weighing between 500g to 1kg = $40_**
    * **_Shipping Rates for products weighing between 1kg to 1.5kg = $80_**

#### Solution using the plugin

Follow the steps below to set up Cart Total Weight Adjustment

  * Download the **WooCommerce Cart Total Weight Adjustment.**
  * Install the plugin on your WooCommerce store and click on plugin settings

  * Click on **Add New** to start adding weight adjustments rules

  * Fill in the following details
    * **Cart Weight Range**  
Provide the cart total weight range based on which you need to enter additional weight
    * **Additional Weight**  
Provide the additional weight which you need to add to the cart’s total weight

  * Click on Save Changes
