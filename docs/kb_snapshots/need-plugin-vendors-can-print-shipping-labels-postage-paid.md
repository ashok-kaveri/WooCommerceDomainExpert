# I need a WooCommerce Shipping Plugin so that my Vendors can Print their Labels with Postage Paid

Do you need a **[WooCommerce Shipping Plugin](https://www.pluginhive.com/product-category/woocommerce-plugin/woocommerce-shipping/)** that will allow your vendors to print their shipping labels with the postage paid? Here’s an awesome plugin for you.

**Customer** :

I am about to launch a WooCommerce Multi-vendor Marketplace using the Dokan plugin. Need a WooCommerce plugin that allows my vendors to print their shipping labels with postage paid.

* * *

**PluginHive Support** :

Currently, the following **[WooCommerce Shipping Plugins](https://www.pluginhive.com/product-category/woocommerce-plugin/woocommerce-shipping/)** from PluginHive support shipping alongside Dokan Multi-vendor plugin.

  1. **[WooCommerce UPS Shipping Plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)**
  2. **[WooCommerce Shipping Plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**

With the above plugins, you would also require our **[WooCommerce Multi-vendor Shipping Addon](https://www.pluginhive.com/product/woocommerce-multi-vendor-shipping-addon/)** to work with the Dokan plugin. If you need any help setting multi-vendor shipping on your WooCommerce store, feel free to contact our **[Customer Support](https://www.pluginhive.com/support/)** team.
