# Setting up Stamps.com Account

In this tutorial, we will show you how you can set up Stamps.com Account to use it in **[WooCommerce Shipping](https://www.pluginhive.com/woocommerce-shipping-services/)**[ ](https://www.pluginhive.com/woocommerce-shipping-services/)**[Services](https://www.pluginhive.com/woocommerce-shipping-services/)** & **[Multi Carrier Shipping Label App](https://www.pluginhive.com/shopify-multi-carrier-shipping-label-app/)**[ ](https://www.pluginhive.com/shopify-multi-carrier-shipping-label-app/)and get real-time shipping rates from Stamps.com on your WooCommerce & Shopify store.

* * *

## How to register for Stamps.com?

  * Go to [Stamps.com](https://www.stamps.com/partner/pluginhive/)
  * Click **Get Started** to sign up.
  * Enter all the required details in the given registration form and click on **Continue**

Once the registration is successful, you will receive the **User ID** and **Password**.

* * *

### Stamps.com API Services

Once you get the Stamps.com credentials, you can use it to display real-time USPS shipping rates for the services listed below.

**Domestic services:**

  * First-Class Mail®
  * Priority Mail Express™
  * Media Mail Parcel
  * Library Mail Parcel
  * USPS Parcel Post
  * USPS Parcel Select
  * USPS Critical Mail
  * Priority Mail®

**International services:**

  * Priority Mail Express International™
  * Priority Mail International®
  * First-Class Package Service™ International.

In addition to this, there are other services which are based on package type. Some of the package types are as listed below:

  * Postcard
  * Letter
  * Large Envelope or Flat
  * Thick Envelope
  * Package
  * Small Flat Rate Box
  * Flat Rate Box
  * Large Flat Rate Box
  * Flat Rate Envelope
  * Flat Rate Padded Envelope
  * Large Package
  * Oversized Package
  * Regional Rate Box A
  * Regional Rate Box B
  * Regional Rate Box C
  * Legal Flat Rate Envelope.
