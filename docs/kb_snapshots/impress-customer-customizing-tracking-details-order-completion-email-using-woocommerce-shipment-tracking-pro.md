# Customize Tracking Details- WooCommerce Shipment Tracking

WooCommerce provides a lot of options for an Online store. But the area where it lacks is the ability to notify the customer as well as the store owner via email. Email notification is one of the smartest to notify the customers as well as the store owner. However, a predefined email template is useless when it comes to impressing your customers. There needs to be a bit of personalization so that your customers feel special.

According to June, one of the WooCommerce store owners,” _**…I want my customers to get the email notification in a different manner as it is right now… My customers get an order completion email where they get the tracking info within the same email…Is there any way to translate the header ”Shipping Detail” to “Följ din****leverans****“..? Appreciate your help.**_ “

In this article, we will be discussing WooCommerce Shipment Tracking Pro plugin and how using that plugin you can change the header for the Order Completion Email based on your preference. This way you can add personalized messages in any language and leave an impression on your customers.

## Changing the Email Header

WooCommerce Shipment Tracking Pro lets you send the tracking details for your packages to the customers. These details are added to the Order Completion email along with the tracking number. WooCommerce store owners can remove the boring header text and personalize it with a message of their preference [**by adding the code in this link.**](https://gist.github.com/xadapter/c132982bdc24cda8294bf88ea5f991f9)

Using this link, you can add your preferred header in any language, and it will be displayed on the Order Completion email. This way you can create personalized messages or translate the text into the local language.
