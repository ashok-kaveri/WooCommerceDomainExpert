# Steps to configure La Poste Colissimo with WooCommerce Table Rate Shipping

The [WooCommerce Table Rate Shipping Pro Plugin](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) facilitates Admin to easily calculate the Shipping rate for La Poste Colissimo services EXPERT FRANCE, EXPERT BELGIQUE, EXPERT OUTRE-MER, and EXPERT INTERNATIONAL. To do this, you simply need to import the CSV file which contains Rule for La Poste Colissimo.

### Steps to configure La Poste Colissimo using WooCommerce Table Rate Shipping Pro Plugin

  1. Install WooCommerce Table Rate Shipping Pro Plugin.
  2. The Admin Settings of WooCommerce Table Rate Shipping Pro Plugin appears as shown below:
  3. Click on **Import CSV** button (highlighted in above screenshot). The screen appears as shown below:
  4. Browse the CSV file ( which you have downloaded in Step 1) by clicking on Choose File or enter the path of CSV file.
  5. Click Upload file and import. The Success Message appears as shown below:
  6. Click View Rate Matrix. It appears as shown below:
  7.
