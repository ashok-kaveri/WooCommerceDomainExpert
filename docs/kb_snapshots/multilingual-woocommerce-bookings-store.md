## WooCommerce Multilingual – Translation vs Localization

When it comes to targeting audiences from different parts of the world, there are two processes that you can use. These are,

  * **Translation**

Translation is the process of converting the content of a website to any other language in the world. This seems perfect when you want customers to know the literal meaning of the content of a website. This way you can convert your product description, features, and policies to the targeted language for the customer to know its meaning.

  * **Localization**

[Localization](https://www.daytranslations.com/blog/the-guide-localization/) is similar to translation as this also requires converting the content of a website to another language. However, localization involves adapting the content based on the language and culture of the people. The focus is less on [grammar](https://studycrumb.com/grammar-checker) or vocabulary and more on the nativity of the language.

## Setting up a WooCommerce Bookings Store in Different Languages

Keeping in mind the concept of language translation and localization, you can easily expand your online bookings store to target either a localized audience or customers from multiple countries.

### How to Provide Online Bookings in Multiple Languages?

To provide online bookings in multiple languages like English, German, French, Italian, Portuguese, etc., you can make use of the popular WordPress MultiLingual plugin (WPML) with the Bookings And Appointments for WooCommerce.

#### WPML and WooCommerce Bookings plugin

To check out how you can set up the WPML plugin check out their documentation regarding the [**WPML Setup**](https://wpml.org/documentation/getting-started-guide/). Once you have installed the WPML and set it up, you can check out the [**How to Set Up Bookings and Appointments for WooCommerce plugin**](https://www.pluginhive.com/knowledge-base/setup-guide-woocommerce-bookings-and-appointments-plugin/).

Once the plugins are set up, your website will have a dedicated Language Widget on your website using which customers can choose their native language and your website will be translated based on their selection.

If you are not able to find your native language in the above list, contact our [**Support Team**](https://www.pluginhive.com/support/) and we will provide you the translation of the plugin in your native language.

Also, the plugin can be easily translated to any language using simple string translation using the translation files.

Bookings And Appointments for WooCommerce plugin can be easily translated with the help of online tools like **POEdit**. All you need to do is visit the bookings plugin folder and open folder **i18n.** Select the**.pot** file and open it using POEdit.

* * *

* * *

Click on **Create New Translation,** and select the language for which you to translate the content of your website.

* * *

* * *

Provide the string translation for the selected language and **Save** the file.

* * *

Once the translation file is created, you will get two files with extensions **.po** and **.mo**. Save these files in the**i18n folder** of the plugin and install the plugin.

****NOTE:  
****Once the translated files are saved in the plugin, contact our support team with the Translation Files. This way we will be able to add the translation files to future versions of the plugin.**
