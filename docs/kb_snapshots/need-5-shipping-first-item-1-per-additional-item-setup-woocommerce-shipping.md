# I need $5 for shipping the first item and $1 per additional item. How to setup WooCommerce Shipping?

WooCommerce store owners have different shipping needs. These shipping needs cannot be fulfilled using the default features provided by WooCommerce. Especially, when it comes to calculating shipping rates.

In such cases, [**WooCommerce Table Rate Shipping Pro**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) is one of the best plugins to provide flexibility in calculating shipping rates. This way the store owners having special shipping requirements will be able to calculate shipping rates without any worries. Take a look at Daniel’s shipping scenario for reference.

According to Daniel,” _**I need $5 as a shipping cost for the first item to be added to the cart. And $1 shipping charge for every additional item. How can I achieve that? I need to do this ASAP. Thank you so much in advance!**_ “

In this article, we will be solving Daniel’s shipping scenario using WooCommerce Table Rate Shipping Pro plugin.

## Calculating Shipping Rates for Daniel

Daniel can easily set up his shipping scenario using WooCommerce Table Rate Shipping Pro plugin. He just needs to select the following fields from the **Matrix Column** from the **Settings tab** that is present in the plugin settings.

  * **Method Title**
  * **Item**
  * **Cost Based On**
  * **Base Cost**
  * **Per Unit Cost**

Once he has selected these fields, he only needs to go to the Shipping Rules Tab to configure his shipping rules. After configuring the shipping, his rules will be similar to the shipping rules shown in the image below.
