# Why does FedEx overnight deliveries shows Delivery – TUE instead of next business day, Monday?

The **[WooCommerce Shipping Plugin for FedEx with Print Label](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** offers a ton of features including FedEx Overnight. But how does the plugin display the delivery date estimates? Check out here to know more.

**Customer** :

When I tried it on Thursday, all of the FedEx overnight deliveries show **Delivery – TUE**. I understand it should be the next business day, but shouldn’t it be Monday rather than Tuesday?

* * *

**PluginHive Support** :

FedEx API returns the service day (time) according to the timezone in which FedEx API is operating. That’s why the business is coming different with the service. Also, we would suggest you contact FedEx with the debug request and response as well.
