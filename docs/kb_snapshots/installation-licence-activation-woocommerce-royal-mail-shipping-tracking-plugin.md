# Installation and Licence Activation

In this article, we will show you how you can easily install and activate the [**WooCommerce Royal Mail Shipping plugin**](https://www.pluginhive.com/product/woocommerce-royal-mail-shipping-with-tracking/) to get real-time shipping rates and shipment tracking on your website.

Royal Mail is a shipping agency of the United Kingdom which provides convenient and affordable shipping and mailing services in the UK (United Kingdom) and internationally. With the help of the WooCommerce Royal Mail shipping with tracking plugin, you can display shipping rates on the Cart/Checkout page. This plugin from PluginHive also comes with the shipment tracking feature. You can also set the packing methods from within the plugin settings page.

## Installation

After purchasing the PluginHive Royal Mail Shipping plugin, the plugin Zip file will be available to download in **My Account** section.

  1. Download the .zip file from **My Account.**
  2. Log in as the WordPress Admin of your online store.
  3. Navigate to **Plugins** > **Add New** to upload the downloaded PluginHive Royal Mail Shipping plugin.
  4. **Activate** the Royal Mail Shipping plugin.

## Find the WooCommerce Royal Mail Shipping Plugin

After installing the plugin, a new shipping method **Royal Mail** is added to WooCommerce. Refer the image shown below. You can navigate to settings in two ways as given below:

  * Navigate to WooCommerce > Settings > Shipping > Royal Mail (under the **Menu** tabs)

  * Navigate to Plugins > Installed Plugins > Royal Mail WooCommerce Shipping > Settings

## License Activation

The first step after installing the plugin is to activate the plugin license. You need to enter the API Licence Key and the email ID used for the purchase. You can find your API License Key in the order completion email or in the API Keys section. As soon as you enter the plugin settings page, you will find the following section on the top section of the settings.

After entering the API Licence key and the Email, you can further click on the **Activate** button to activate the plugin. You can also follow up with the following video which will show you how to install and activate the plugin.

This way the plugin will be successfully installed on your WooCommerce and you can start using the plugin.
