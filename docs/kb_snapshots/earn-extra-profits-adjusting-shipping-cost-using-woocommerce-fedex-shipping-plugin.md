## Shipping Rate Adjustment with WooCommerce FedEx Plugin

**[WooCommerce FedEx Shipping Plugin](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)** allows store owners to provide real-time accurate shipping rates directly from FedEx. However, using this plugin, store owners can easily include additional charges to the shipping rates and cover up their loses. WooCommerce FedEx Shipping plugin allows store owners to adjust shipping rates in two ways.

  * **Adding a Flat Rate value to the shipping rates**
  * **Increasing Shipping Rates by some percentage value of the shipping cost**

**[WooCommerce store](https://www.pluginhive.com/woocommerce-tutorial-for-novice/)** owners can choose the shipping option for which they want to adjust the shipping rates. They can find the shipping option in the plugin settings. There they can add the values in the**Price Adjustment** columns to increase the shipping rates.
