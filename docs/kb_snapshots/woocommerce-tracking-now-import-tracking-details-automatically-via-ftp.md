## Automatically Import WooCommerce Order Tracking Details

Apart from providing live tracking updates, the **[WooCommerce Shipment Tracking plugin](https://www.pluginhive.com/product/woocommerce-shipment-tracking-pro/)** offers many advanced features. One of helpful automation feature is the importing of the automatic tracking data from a remote server using FTP upload method.

With the help of this feature, you can easily upload a CSV file containing the shipment tracking data stored on a remote server. The plugin provides a mechanism to automatically schedule the import based on the server current time.

However, if FTP is not an option then users can even upload the CSV file directly from your local computer. The plugin even allows you to schedule the automatic import periodically, giving you enough time to work on other important aspects of your business. Let’s check out both the features in detail.

### Importing WooCommerce Order Tracking Details via FTP upload

WooCommerce store owners can access the import section of the plugin by clicking **WooCommerce → Shipment Tracking Import**. Once you’re there, you will have to click on **Enable FTP** option as indicated in the image below.

Once it is enabled, it will show the section where the store owners will need to add the FTP credentials, as well as the path of the CSV File which contains the tracking data. Refer to the image above.

### Automatically Importing WooCommerce Order Tracking Details via CSV upload

Since the whole point is about automating the process of importing tracking details, store owners can schedule the import by enabling the **Automatically Import CSV** option.

It will enable the store owners to schedule the import based on the preferred time. However, you need to enter the time carefully since the plugin shows the current server time, thus, you need to enter the scheduled time based on that time.

**For example, if the current time shown on the plugin page is 8.21 pm, and the store owners require to schedule the import at 8.30 pm, so he needs to enter the time as 8.30 pm.** Also, by providing the Import Interval, store owners can schedule the import periodically after the desired minutes.

**NOTE:*****To import folder using FTP, the customer should specify the pathname ending with ” /.* “**

**( Ex: FTP/LESOutboundLive/DESP/.* ).*********If this still does not work, try with enabling the passive mode.***

The image shows the scheduling process configured at 8.30 pm and the importing will again start at the same time the next day, i.e. every day after 1440 minutes.

#### WooCommerce Shipment Tracking Details in the Order Completion Email

Once the import finishes, the orders that were to be updated would be automatically marked as ‘Completed’. Your customers will receive the corresponding order tracking details along with the Order Completion Email.

In the sample email above, you can see the tracking number, carrier information, date of shipment as well as a link to track the shipment on carrier’s website. The image shows the details that a customer will receive in the **Order Completion Email**.

This way the store owners need not worry about their customers asking for the tracking details again and again. Also, this eliminates the need for a dedicated person just to update the tracking details and provide it to the customers.
