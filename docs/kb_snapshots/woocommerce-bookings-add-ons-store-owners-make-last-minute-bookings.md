# WooCommerce Bookings Add-ons – Allow store owners to make last-minute Bookings

With the Bookings and Appointments for WooCommerce plugin, the store owners get the option to decide how much time in advance the users can place a booking. Most of the time, the store owners do not want the users to make bookings at the last minute to have the preparation time.

However, when the **Avoid last-minute booking setting** in the Bookings and Appointments for WooCommerce plugin is set to, say 1 hour or 1 day, it does not allow the admin to override it and make a last-minute booking from the admin page.

This add-on disables the last-minute bookings option for the bookings placed by the store owner from the front end and back end. It allows the administrator to place bookings for the slots that are disabled/unavailable due to the “Last minute Bookings” option available in the Booking Availability settings tab. ## How to set it up?

  1. Contact our support team and get the paid **Disable Last-minute Bookings for admin bookings add-on** and install it on your WooCommerce store
  2. Administrators can visit the desired bookable product on the shop page or from the back end (Add Bookings) to place a booking for the slot
  3. The administrator will be able to place bookings for the slots that are disabled/unavailable due to the “Last minute Bookings” option available in the Booking Availability settings tab as shown below
