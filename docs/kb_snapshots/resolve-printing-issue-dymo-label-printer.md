# How to resolve printing issue with Dymo label printer?

Are you using the WooCommerce UPS Shipping Plugin with Print Label with Dymo Label Printer to print shipping labels? But you sometimes face a few printing issues when doing that. Read below to see the solution.

**Customer:**

Hi, I can create a shipping label but it’s the single 8×11 sheet of paper type. I own a Dymo label printer that prints 4×6 labels. What do I have to change in the plugin settings to create a 4×6 pdf label?

* * *

**PluginHive Support:**

Currently, our UPS plugin prints labels in PNG, GIF, ZPL, and ePL formats. The size of the label depends on your printer settings. You can go through the articles below for more information:

  * [How to adjust the Dymo label writer paper size for Windows?](https://support.vintrace.com/hc/en-us/articles/32303322393748-Set-up-DYMO-label-paper-sizes)
  * [How to print labels using a Dymo label printer for Mac?](https://help.ricoconsign.com/en/articles/2508345-setting-up-a-dymo-450-or-550-label-printer-macos)
