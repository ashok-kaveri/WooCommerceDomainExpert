# WooCommerce UPS Plugin v.3.9.15: Estimated Delivery Options, Bulk Label Printing

In this article, we will explore the latest features added to the [**WooCommerce UPS Shipping Plugin**](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/) for version 3.9.15. Read below to learn more about these features and find out how they can help you.

WooCommerce UPS Shipping plugin is the #1 shipping plugin that provides an automated way to ship your products via UPS. However, with this latest release, the plugin is now more complete than ever. This time we have introduced an option to display the estimated delivery date for the shipments. It will help customers get an idea of when their package will be delivered. Also, bulk label printing will make label printing a much faster process.

Besides these features, there are a few improvements and small fixes that will ensure a smooth experience while using the plugin. So, here is the changelog for the **UPS Shipping Plugin v3.9.15.**

* * *

### New Features

  * **New Estimated Delivery Date option**
  * **Now Volumetric Weight option for Weight-Based Parcel Packing**
  * **Bulk Label Printing in PDF and PNG format**
  * **Send Shipping Labels for Shipper and Customer**
  * **Custom Message in Order Completion Email**

Along with the above features, there are tons of improvements and fixes. You can check out the complete changelog in the [**link here**](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/). Now, let us see how to make the most out of the features listed above.

## i. Estimated Delivery Date option

UPS provides delivery estimates for some of its shipping services. The estimated delivery dates are subject to the source and destination address and how accurately you set these addresses. Also, you can now set the plugin to get the estimated delivery date directly from [UPS](https://wwwapps.ups.com/time) and display it on your website. The image below shows the option to enable the estimated delivery date in the UPS shipping plugin.

* * *

Once enabled, this option will allow customers to get the delivery estimates on the cart page. However, in case, there is a shipping service for which UPS doesn’t support delivery dates, the shipping rates won’t be displayed as well. The image below shows the estimated delivery in case of some UPS shipping services.

## ii. Volumetric Weight

**[UPS Shipping plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)** already provides a way to pack your products and get shipping rates based on the weight of the products. However, in some special shipping scenarios where the products can require more space even with lesser weight. One such example is pillows. Shipping products like pillows can lead to confusion while shipping as the volumetric weight in the case of the pillows would be more compared to the actual weight. Hence, the UPS shipping plugin now supports another way to compare the actual weight and the volumetric weight of the products.

* * *

* * *

The image above displays the option which will allow the plugin to compare the actual weight and the volumetric weight of the products. In case the volumetric weight exceeds the actual weight, the plugin displays the shipping rates based on that weight.

## iii. Bulk Label Printing in PDF and PNG format

The WooCommerce UPS Shipping plugin makes shipping label printing a faster process. Using the plugin, WooCommerce store owners can make sure they print and download shipping labels for all their orders in one go. UPS shipping plugin allows you to select all the orders, and then generate the shipping labels for all of them. And similarly, you can get the shipping labels for all the orders you have selected by choosing the option from the image below.

## iv. Send Shipping Labels to Shippers or Customers

A large number of WooCommerce store owners requested a feature that will enable them to send shipping labels to the shipper and the customers. The image below shows the option in the plugin settings to select who will get the shipping label. The store owner can choose either the shipper or the customer and send them the shipping label via email.

## v. Custom Message in Email containing Shipping Label

**[WooCommerce UPS Shipping plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)** also comes with a new way to customize the way you interact with customers. Now you will be able to create a custom message for your customers and send it via email. This message will be displayed in the Email containing the shipping label.
