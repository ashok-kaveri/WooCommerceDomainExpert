# WooCommerce Canada Post Manifests for Domestic & International Shipments

WooCommerce store owners can use shipping plugins for a variety of functionalities that are not there by default. some of them include printing the invoice, packing products, getting the shipping labels for their shipment, etc. One such feature which is specific to a shipping carrier is the Canada Post Manifests. The manifest allows store owners to list all the packages that are to be sent via Canada Post along with package details.

According to Mia, a WooCommerce store owner,” _**…I ship via Canada Post domestically and internationally. Is it possible to get the Canada Post Manifest for both the domestic as well as international orders..? How can I print the manifest using your plugin..? Let me know if this plugin supports a feature like this. Thanks.**_ “

In this article, we will cover the [**WooCommerce Canada Post Shipping plugin** ](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/)and how using this plugin you can print Canada Post Manifests for your domestic as well as international shipments.

## Printing Canada Post Manifests

WooCommerce Canada Post Shipping plugin allows store owners to get real-time shipping rates from Canada Post. Based on the shipping rates, store owners can easily print the shipping labels and send it to the customers also. However, to print the Manifest, there are some things that you need to take care.

  * **To print the manifest, the shipment must be created for every order.**
  * **A shipping label must be generated for every order.**
  * **To print the manifest, you only need to transmit the shipments once.**
  * **Domestic and International Orders will have separate manifests.**
  * **The manifest will include only those orders, which were placed after printing the previous manifest.**

If all these things are taken care of, you can print the Canada Post Manifest directly from the order page. All you need to do is click on **Transmit Shipment**. What it does is that it includes all the details of every order which is ready for pick up by a Canada Post-authorized driver. The image below will show you the option to transmit the shipment.

Once you are done with this, you can print the manifest by clicking on the**Print Manifest**. As discussed, in case you are having both domestic and international shipments, separate manifests will be generated. The image below shows two separate options to print manifests.
