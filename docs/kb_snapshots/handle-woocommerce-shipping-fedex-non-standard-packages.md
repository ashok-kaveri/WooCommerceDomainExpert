## What is a FedEx Non-Standard Package?

FedEx applies additional fees based on certain packaging characteristics. Packages classified as Non-Standard include:

  * Any package longer than 60 inches but not exceeding 108 inches in length
  * Packages not fully enclosed in an outer shipping container
  * Packages enclosed in an outer shipping container made of wood
  * Drums or pails (under 5 gallons) not fully enclosed in a corrugated cardboard container

With this understanding, let’s explore how to apply these Non-Standard packaging surcharges at the product level using the [WooCommerce FedEx Shipping Plugin](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/).

### How to Enable Non-Standard Option for a Product Variation

When it comes to variable products, not all variations may require Non-Standard packaging. Some variations might need special handling, while others can be shipped using standard packaging. To manage this, store owners need a way to apply Non-Standard packaging selectively.

The [WooCommerce FedEx Shipping Plugin](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/) provides this flexibility. It allows you to enable the Non-Standard packaging option individually for each product variation. As shown in the image below, you can configure this setting directly in the variation settings.
