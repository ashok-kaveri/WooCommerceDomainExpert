# Does WooCommerce Canada Post Shipping plugin works with Currency USD?

WooCommerce has an option to work with almost every country and currency in the world. In this article, we will be covering [**WooCommerce Canada Post Shipping plugin**](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/) and configure the plugin such that it works with the currency set as USD.

## Changing Currency to USD

Canada Post requires the shipment origin address as Canada. However, it doesn’t limit the WooCommerce Canada Post shipping plugin’s ability to work with currency set as USD. The shipping rates will, however, be returned in Canadian Dollars (CAD) by the Canada Post API. So the only way to successfully convert the currency and make sure the shipping rates are returned accurately is to provide the**conversion rate** in the plugin settings. The image shows the **CAD to USD conversion rate, i.e. 0.78.**

Now since we know the conversion rate, we can configure the plugin settings to show the shipping rates in USD. For this, we need to change the default **Conversion** option to 0.78. The image below shows the currency conversion rate option in the plugin settings.

Once you have set the conversion rate, the shipping rates will be visible to the customers as a converted USD value of the CAD shipping rates.
