# Is it possible to do a bulk import of tracking data using comma separated file?

If you require a WooCommerce Shipment Tracking solution that can import tracking details to bulk orders, this article will surely help you.

**Customer** : Is it possible to do a bulk import of tracking data using comma-separated files with the WooCommerce Shipment Tracking Pro plugin?

* * *

**Support** : Yes. It is possible. Once uploaded, the order will be auto-marked as completed and mail will be triggered in turn with tracking details.
