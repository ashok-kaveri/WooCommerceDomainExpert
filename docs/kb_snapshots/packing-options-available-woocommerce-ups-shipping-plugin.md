# Efficient Parcel Packing with WooCommerce UPS Plugin

In this small guide, we will tell you the various parcel packing or box packing options that you get with the WooCommerce UPS Shipping Plugin with Print Label. Read below to know more about it.

[**Woocommerce UPS Shipping plugin**](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/) has three primary packing options available. You can set the **Packing Method** in the plugin settings.

– With Box Packing & Pack Items individual options dimensions & weight will be considered to calculate the shipping cost.  
– With the Weight-based option, only the weight will be considered to calculate shipping cost.

* * *

## WooCommerce UPS Packing methods

  * **Pack Items Individually** : In this option, each item in the cart is packed separately. The total Shipping cost is calculated by adding the shipping cost for each item. Hence labels are also generated separately.  
For example, the shipping cost of Item X is $10. If the customer adds two units of item X to the cart, then the total shipping cost is $10 x 2, which is $20. In this case, two labels are generated.  
Note: This is the default option.  

  * **Pack into boxes with weight and dimensions**: If packing items individually does not suit your business, you can define the required box sizes under the Box Dimensions section. All the cart items are packed into custom boxes defined in the Box Dimensions settings. The best-fit box is auto-chosen from the defined boxes. This is the recommended option. You can read through “**[Box Packing](https://www.pluginhive.com/knowledge-base/box-packing-calculation-shipping-rates-based-weights-dimensions-2/)** ” to understand more in detail.  

  * **Weight-based** : In this option, the weights of all the cart items are summed up and passed to the UPS API to get rates. You have to just define a **Max Weight** which will determine the maximum weight that can be packed in a single package. All the products up to the Max Weight will be packed inside a single package and once the Max Weight is reached, the plugin will create a new package. Read More about [**Weight Based Packing**](https://www.pluginhive.com/knowledge-base/weight-based-packing-ups-shipping-plugin/) here.

These straightforward options make this plugin a powerful one that fulfills your business needs for efficient parcel packing.
