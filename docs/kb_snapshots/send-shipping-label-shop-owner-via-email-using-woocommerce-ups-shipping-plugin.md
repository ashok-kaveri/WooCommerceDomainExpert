# Send WooCommerce UPS Shipping Label via Email

In this article, we will be discussing the [**WooCommerce UPS Shipping plugin**](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/) and how can you allow customers as well as store owners to get the UPS shipping label via email.

WooCommerce UPS Shipping plugin allows customers to get shipping labels via email. But what about the shop owner..? and even the vendor, or the warehouse manager..?

Sometimes WooCommerce store owners have to get shipping labels urgently and in such cases, logging in to the WordPress dashboard and then visiting the orders to get the shipping labels is the last thing they would want to do. Moreover, in the case of multiple warehouses, you need to make sure they get the shipping labels to ship the packages to the correct address.

According to Sam, a WooCommerce store owner, “ _**I see there is an option for sending the label to the customer once it is created. How can I send an email to myself – the shop owner, as well as my warehouse keeper? It’s more convenient and much faster for us to open an email and print, than having to go to the backend, go to the order details page and then print. The person at our warehouse that handles this job is older as well, so these are a lot of steps and too complicated for him.**_ “

* * *

## Adding Email IDs

To get the shipping label via email, store owners need to set up their email id or the store’s dedicated email ID. Once it is done, you need to set the **Send Shipping Label via Email** option to **Shipper.** You can also set this to both the shipper as well as the customer, and the plugin will send the shipping label to both the store owner as well as the customers.

* * *

Also, in case of a multi-vendor scenario, you can send the shipping labels to the vendors. In such cases, another option for Vendors will also appear in the settings. Just select the **Vendors** option and **save** the settings. Once you save the settings, the plugin will send the shipping labels via email, as shown below.

## Summary…

So this article covers generating WooCommerce UPS Shipping label using the UPS Shipping plugin and then sending them to the store owner, customers as well as vendors, via email. Shipping labels contain important information about the source and destination address. However, in some cases, the store owner may not be able to get the shipping label from the WooCommerce Order’s page. Hence, we require some mechanism to deliver the shipping label to the store owner via email.
