## Hide the column(s) that are not used

Not all the columns in the Rate Matrix are used by all business.  
Let’s take a case where you don’t need following columns for your business

  * No Country/State/Postcode criteria to configure shipping rule.
  * No Price/weight: Shipping rate calculated based on Quantity.
  * No Shipping class or Product Category based shipping.

You can hide above listed columns and use only the columns which are important for your business.

It is convenient to display only the needed columns for business. And did you see the Display/Hide matrix columns has selected only 7 columns now? You can select the remaining columns whenever your business demands them.

## Import a huge list of shipping rules onto your WordPress/WooCommerce website

Let’s assume you have far too many shipping rules, say 4800, to be uploaded into the plugin settings page. How do you manage and import such huge data into the plugin?

Well, the best way to configure rules in the WooCommerce Table Rate Shipping Pro plugin is to create the shipping rules in a CSV. Once that is done, you can import the CSV file using the Import/Export CSV option provided in the plugin. All rules will be imported perfectly.

### How to combine multiple WooCommerce shipping rules into a single rule?

While uploading or adding a large number of shipping rules for different type of products, there are times when the shipping will be calculated for all the products based on a single factor, for example total weight. In such a scenario, you can combine the shipping rules for individual products using the WooCommerce Shipping Classes or WooCommerce Product Categories.

All you need to do is create a single Shipping Class or Product Category. Then, you need to add all of the products for which the shipping has to be calculated based on weight to the Shipping Class. Thereafter, you can create a single rule for the whole Shipping Class and set the shipping cost per weight.

This way, a single rule will calculate the shipping cost for all the products within the Shipping Class, and it will be easier to edit or modify the rule in the plugin settings as well.
