# Customize Product Description on Label with WooCommerce UPS Plugin

In this guide, you will learn how to customize the product description mentioned on the Label when using **[WooCommerce UPS Shipping plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)**. We will discuss a unique case where an online seller wants to hide certain sensitive information from the label.

## The Business Case – Customize Product Description

UPS label provides essential information that enables both you and the delivery agents to process shipments faster. It contains various important information such as shipping address, delivery service name, estimated delivery date, and shipment weight.

The product description, a necessary piece of information when it comes to delivering items, is also present on the label. However, certain businesses would rather prefer not to display certain product information on the label.

Businesses that deal with items that are sensitive in nature, like legal documents or medical products, often choose to conceal most details from the outer world. In such cases, it makes sense to hide the information from the label or package receipt.

We had a similar experience where one of our customers wanted to remove specific information from the label. Let’s check out his query to understand the case better.

> _I don’t know if you have plans for this in the future but it would be very very helpful if there was a way to customize what was printed on the label. My client sends medical products and because of its sensitive nature, they do not want the product description or the phone number listed on the label. I have manually removed these from the labels via editing the plugin code but this needs done every time there is an update. If this could be added as a plugin option in the future that would be amazing. Thanks!_
>

## Solution using WooCommerce UPS Shipping plugin

Being intuitive and flexible as it is, the **[WooCommerce UPS Shipping plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)** is capable of allowing users to make certain changes in the label. This includes the removal of the product description and phone number completely. Let’s explore this feature.

#### Shipment Description For UPS Label or Commercial

The above set of options allows you to configure and customize product description. Starting with the ‘Shipment Description For UPS Label or Commercial’, this option lets you choose what type of information should be displayed on the label. Here you have three options to choose from.

  1. Product Name: This option will let the plugin print the name of the product and nothing else.
  2. Product Category: This option will print only the Category of the product. For instance, Syringes, Medicines, etc.,
  3. Custom Description: With this option enabled, you can provide your own custom text up to 50 characters and 35 characters for commercial invoices.

**Note:** Although **[WooCommerce UPS Shipping plugin](https://www.pluginhive.com/product/woocommerce-ups-shipping-plugin-with-print-label/)** allows users to enter 1-50 characters, we cannot guarantee that the entire description will be printed. UPS may limit the number of characters entered to accommodate other parameters on the label. So we advise you to enter up to 45 characters to avoid unnecessary character elimination.

Next comes the option to include the Order Id in the shipment description. As the name suggests, you can allow the plugin to include the Order Id along with the product description. Please keep in mind that the Order Id, if enabled, will take up some number of the 50 characters.

The second option lets you include the Shipment Description on the Commercial Invoice. But if you choose not to enable it, the default setting will force Commercial Invoice to include only the Product Name.

Since the minimum number of characters required is 1, you can’t leave the ‘Custom Description’ section blank if you want to hide the information completely. In the image displayed above, we have mentioned **NA** as a symbol to hide product information.

#### Remove the Recipients Phone Number

Once you enable this option, the plugin will hide the recipient’s phone number on the label for selected Domestic shipping services. However, keep in mind that adding a customer’s phone number is mandatory for international shipments and a few domestic services. So in case, a service that requires a phone number is used, the plugin will ignore this option and will display the phone number.
