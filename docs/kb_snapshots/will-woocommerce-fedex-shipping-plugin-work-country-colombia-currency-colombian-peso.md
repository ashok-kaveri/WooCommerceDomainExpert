## Checking the Official FedEx website

WooCommerce FedEx Shipping plugin provides shipping rates from the official FedEx API (based on your Official FedEx Account). Hence, all the countries and currencies supported by FedEx will be automatically supported by the plugin. That’s why you need to check the Official FedEx website to check whether it supports the country Colombia and which shipping services it provides from there. For this, you can [**visit this page** ](https://www.fedex.com/ratefinder/home?cc=bq&language=en)and check by entering the **Ship From and Ship To addresses.**
