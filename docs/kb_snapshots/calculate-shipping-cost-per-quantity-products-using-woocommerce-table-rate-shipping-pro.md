# Calculate Shipping Cost Per Quantity of Products- WooCommerce Table Rate Shipping Pro

In this article, we will be covering how to create shipping rules such that the shipping rates will be calculated based on the quantity of product added to the cart, using [**WooCommerce Table Rate Shipping Pro**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) plugin.

There are not many options when it comes to personalizing shipping rates based on the store owner’s preferences. [**WooCommerce Table Rate Shipping plugin**](https://www.pluginhive.com/product/woocommerce-table-rate-shipping-pro-plugin/) allows store owners to create shipping rules based on a lot of factors. These factors include product weight, quantity, price, shipping classes, destination address, etc. This way the plugin can help in achieving lots of shipping scenarios.

According to John, a WooCommerce store owner, “ _**…We sell products that we want to be shipped based on the quantity like, if there is one****product shipping rate should be $12, if there are two it should be $13.5. If there are three to five products, shipping should be $22 and for ten products in the****cart****, shipping should be $39, and so on… How can I set the shipping to calculate per quantity of products..? Is there any way to do it..?**_ “

* * *

## Creating Shipping Rules

The WooCommerce Table Rate Shipping Pro plugin allows store owners to select the factors based on which they can create shipping rules. In the case of John, since he wants the shipping rates to be based on the product quantity, he needs to select the following from the **Matrix Columns** in the plugin’s settings tab.

  * **Method Title**
  * **Method Group**
  * **Item**
  * **Rates Based On**
  * **Base Cost**
