## What is UPS Control Log Receipt?

A UPS Control Log Receipt is a document affixed along with shipments that contain insured items worth more than 1,000 €. The UPS API allows the users to automatically print the Control Log receipt with the ‘**ShipmentAcceptResponse** ‘ tag.

As per UPS documents, you can get the Control Log receipt for the forward shipments with a declared value (insurance) ranging between $999 and $50,000.

One of our customers wanted to ship from Germany to other parts of the world. He was having a query regarding the control log receipt. Let’s check out the query.

> _When insuring goods worth more than 1000 EUR the ShipmentAcceptResponse automatically seems to include a control log receipt. This, however, looks very different than what we get from accessing the UPS website manually. Does your WooCommerce UPS Shipping plugin support this?_

* * *

Let’s see how the WooCommerce UPS Shipping plugin helps in creating the Control Log Receipt.

### Creating Control Log Receipt using WooCommerce UPS Shipping plugin

As mentioned above, you can get the Control Log receipt for the forward shipments with insurance values ranging between $999 and $50,000. So, for the products whose declared value ranges between this amount, you can print the control log receipt.

Under your store dashboard, head to **Products →** **Select the particular product →****Shipping →****UPS Shipping details →****Custom Declared Value**.

If the custom-declared value ranges between $999 and $50,000, you can print the Control Log receipt for the particular product. Consider the example,

For the product “Vneck Tshirt”, a declared value of $2000 is added.

Once the order is placed and it is confirmed, you can see the option for generating the Control Log Receipt under the particular order details.

## What is UPS Recipient Tax Identification Number?

A **Tax Identification Number**(TIN) is a number issued to individuals and organizations to track tax payments they make to the Internal Revenue Service(IRS). A TIN can be assigned by the Social Security Administration for individuals, or by the IRS for businesses and other organizations.

One of our customers wanted to ship from Canada to other parts of the world. He wanted to add an option of the recipient tax identification number.

> _I could not find any plugin which allows to enter receiver’s TaxID and have it in shipping docs. The only way I’ m managing is by logging into UPS website and ship it with correct options configured via UPS website. Will your WooCommerce UPS Shipping plugin handle this feature?_

* * *

## Solution using WooCommerce UPS Shipping Plugin

WooCommerce UPS Shipping plugin allows store owners to enable the option to add to the recipient tax identification number and also helps to print the control log receipt.

You can enable the Recipient’s Tax Identification Number under the WooCommerce settings. Head to **WooCommerce settings** < **UPS** < **Advanced Settings**. Now, Enable the Recipient TIN.

Once the Recipient TIN is enabled, the customer gets an option to enter their Tax Identification number at the checkout page.

When the customer places the order by entering the Tax Identification Number, the store owner can edit this information before confirming it from the WooCommerce orders page. This option is useful if the customer had entered a wrong Tax Identification Number and it needs to be corrected.
