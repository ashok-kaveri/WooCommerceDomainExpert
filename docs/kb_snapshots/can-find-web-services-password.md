# Where can I find the Web Services Password for FedEx?

This guide will help you find the FedEx Web Services Password for FedEx. You can use this as a solution when using the WooCommerce FedEx Shipping Plugin with Print Label.

**Customer** :

I went to the “Move to Production” section in the FedEx account and found the meter number, account number and web services key, but where can I find the web services password?

* * *

**PluginHive Support** :

When you contact FedEx for the credentials, they send you two emails. One that contains the account number, meter number and web services key and the other contains the web services password.
