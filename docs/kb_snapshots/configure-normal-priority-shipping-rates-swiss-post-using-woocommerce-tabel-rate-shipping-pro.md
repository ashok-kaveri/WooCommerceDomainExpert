## Creating Shipping Rules

Viktor’s shipping scenario can be easily configured using the WooCommerce Table Rate Shipping Pro plugin. What Viktor needs is that his shipping must be based on the weight of the products added to the cart. Based on these requirements, he needs to select the following **Matrix Columns** from the **Settings tab** under the plugin settings.

  * **Method Title**
  * **Weight**
  * **Rates Based On**
  * **Base Cost**

Also, he needs to select the calculation mode to **Per Order** and then save the settings. Once this is done, he can easily create his shipping rules in the **Shipping Rules** tab in the plugin settings. The image below shows Viktor’s shipping rules based on his requirements.
