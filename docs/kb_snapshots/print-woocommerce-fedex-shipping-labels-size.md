## Label size and type offered in the plugin

There are quite a lot of options for you to print the required shipping labels for your business. Let us first see the various label sizes available.

### Label size

  * PAPER_4 x 6: Generates labels with a size of 4 x 6 inches
  * PAPER_4 x 8: Generates labels with a size of 4 x 8 inches
  * PAPER_4 x 9: Generates labels with a size of 4 x 9 inches
  * PAPER_7 x 4.75: Generates labels with a size of 7 x 4.75 inches
  * PAPER_8.5 x 11_BOTTOM_HALF_LABEL: Generates labels with a size of 8.5 x 11 inches at the bottom half of the paper
  * PAPER_8.5 x 11_TOP_HALF_LABEL: Generates labels with a size of 8.5 x 11 inches at the top half of the paper
  * PAPER_Letter: Generates labels with a size of 8.5 x 11 inches

For Thermal printers, the following are the label sizes available –

  * STOCK_4 x 6
  * STOCK_4 x 6.75_LEADING_DOC_TAB
  * STOCK_4 x 6.75_TRADING_DOC_TAB
  * STOCK_4 x 8
  * STOCK_4 x 9_LEADING_DOC_TAB
  * STOCK_4 x 9_TRADING_DOC_TAB

Thus, if you are using a thermal printer to print your FedEx shipping labels, then it is recommended that you go for the STOCK sizes. Doing this will produce optimized labels that include all the label data without any formatting errors

* * *

### Label/image type

There are in total five types of image formats available for you. Following are the options.

  * **PDF** : It is a Portable Document Format that is used to present documents in an independent manner of application, software, hardware, and operating systems.
  * **PNG** : The full form is Portable Network Graphics. This format has a raster graphics file format that supports lossless data compression.
  * **DPL** : It is the short form of Datamax Programming Language. Only DPL-supported printers can decode this type of image format.
  * **EPL2** : Eltron Programming Language is a type of printer control language. It is the older version of the ZPL format and is still widely used.
  * **ZPLII:** It is the Zebra Programming Language which is a type of page description language that is widely used by many printers.

## Print labels based on the type of label printers

Often, online store owners ponder before selecting the right label printing machines for their business. They have to make sure that it meets their budget and satisfies their business needs as well. And being a WooCommerce store owner, you should make sure that the label generation process is simple.

* * *

### Thermal Printers

Thermal printers are best suited to print any label that is **4 x L,** where L may contain any value. Moreover, the labels are always in vertical form. Thus, by looking at the various sizes offered in our plugin, you can print the following sizes using any thermal printer.

  * STOCK_4 x 6
  * STOCK_4 x 6.75_LEADING_DOC_TAB
  * STOCK_4 x 6.75_TRADING_DOC_TAB
  * STOCK_4 x 8
  * STOCK_4 x 9_LEADING_DOC_TAB
  * STOCK_4 x 9_TRADING_DOC_TAB

Moreover, you have to make sure that you **do not select PDF** as the image format if you are using thermal printers. It is not that it will not print the labels, the issue is that the format of the printed labels might not be perfect.

Keeping these things in mind let us check out the two types of thermal label printers available for you.

#### Thermal transfer printers

Thermal transfer printers are the most widely used label printers. They are known for their high-quality and long-lasting labels. There are a variety of thermal printers available that can range from low cost to high cost. Usually, costlier printers are used by bigger industries or companies in order to print a high volume of labels. These printers come with ink ribbons that are used to print high-quality labels. The ink ribbons are usually made of wax and resin.

These printers are a bit costlier than other types of printers, but the maintenance is quite budget-friendly. These printers are built to last longer and tend to work pretty well. They could be a very good choice for your business if you’re looking for better-quality labels.

#### Direct thermal printers

These types of printers do not require an ink ribbon. Getting into specifications, the labels used contain a special layer of chemicals beneath the surface of the label and react to the heat. This is how the letters and images are formed on the labels. This results in a decrease in the cost per label. Direct thermal printers are very easy to set up and use as your daily label generators. Moreover, some Direct printers can switch back and forth between thermal and direct transfer printing.

However, the labels used in the printers are a tad expensive because of the chemical used on them. This increases the maintenance cost which might not be good for your budget. On the other hand, some cheaper printers produce low-quality labels that tend to fade away with time.

* * *

### Normal printers

Laser and Inkjet printers come under this category. These types of printers are more economical and make an excellent choice for on-demand printing. They can be easily used as a home or office printer. Moreover, the maintenance cost of these printers is quite low and their durability is also outstanding. But, despite offering such great features and being cost-effective, these printers cannot print multiple labels at a time. This makes them slow which is not good for any online business.

Now, let us check out the types of supported formats for normal printers.

  * PAPER_7 x 4.75: Generates labels with a size of 7 x 4.75 inches
  * PAPER_8.5 x 11_BOTTOM_HALF_LABEL: Generates labels with a size of 8.5 x 11 inches at the bottom half of the paper
  * PAPER_8.5 x 11_TOP_HALF_LABEL: Generates labels with a size of 8.5 x 11 inches at the top half of the paper
  * PAPER_Letter: Generates labels with a size of 8.5 x 11 inches

While using a normal printer, you should **choose the image type as PDF** for better quality and format. These printers print 2 pages at maximum and thus, are best suited for 8.5 x 11 sized labels.

* * *

### Printers for other formats

For other formats including DPL, EPL2, and ZPLII, you have to have printers that support those formats. For example, if you have a printer that supports DPL printing, you should choose the image type as DPL and then proceed with the label generation process.

Moreover, you should choose the right format size based on the type of printer. Thus, if the EPL2 thermal printer supports 4 x 8 inches labels, then you should choose STOCK_4 x 8 as the label size and EPL2 as the image type.
