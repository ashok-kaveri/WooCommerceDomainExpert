# Code snippet to display the Shipping phone number on the WooCommerce Shipping label instead of the Billing phone number

Here’s a code snippet to display the shipping phone number in the WooCommerce FedEx Shipping label instead of the billing phone number when using the **[WooCommerce Shipping Plugin for FedEx with Print Label](https://www.pluginhive.com/knowledge-base/woocommerce-tracking-number-for-fedex-shipments-in-order-completion-email/)**.

By using this [**code snippet,**](https://gist.github.com/PluginHive/78ca24fde27bf33a4824aceb4f55a4e1) you can display the shipping phone number in a label in place of the billing phone number. Add the above code snippet in to Appearance --> Editor --> functions.php.

The screenshot below shows the billing and shipping address and phone numbers.

**Without Using Snippet** : The billing phone number appears in the shipping label.

**After using Snippet** : The shipping phone number appears in the shipping label.
