# How to Set up Bookings for Wine Tasting Session using WooCommerce Bookings Plugin

In this guide, we will tell you how to set up an online booking system for a wine tasting session with the help of **[WooCommerce Bookings plugin](https://www.pluginhive.com/product/woocommerce-booking-and-appointments/)**. We will take a real-life example to show you how it can be done.

## The Business Case – Wine Tasting Session

The **Dutch Wine Tasting** can be booked on every **Monday** and **Friday** at **02.30PM**. The wine tasting experience will take about **75 minutes**. And the cost of a wine tasting is **€54 per person** which include all the wines, cheese, and snacks.

The Booking conditions are as follows. Participants/guests must be no less than 4 and more than 6. So the number of participants per session must be locked at a maximum of 6 while the session cannot take place if the number of people is less than 4.

Let’s check out how this can be achieved using our **[WooCommerce Bookings](https://www.pluginhive.com/product/woocommerce-booking-and-appointments/)** plugin.

## Solution using **[WooCommerce Bookings](https://www.pluginhive.com/product/woocommerce-booking-and-appointments/)**

  1. **Create a bookable product, say, The Dutch Wine Tasting and provide the booking details and the instructions for the booking (optional) within the product description.**
  2. **In order to set up the Booking only on Monday and Friday at 2.30 PM, provide the daily booking opening and closing times at 2.30 PM provide the Availability rules, that is the booking to be placed only on Monday and Friday under the “Booking Availability” section within the specific product settings page.**
  3. **In order to provide 75 minutes blocking slot, the booking period should be set to 75 minutes.**
  4. **To set the minimum participants as 4 and max as 6 for booking per session and cost per each participant as 54 euros, enable “consider each participant as a separate booking” within the Booking Participants tab along with it provide the min as 4 and the max as 6 and cost for each participant accordingly. Please note that maximum bookings per block also need to be set to 6 within the Bookings tab.**

Voila! Now we have set up a complete wine tasting session based upon the above business case. So, if a customer books for 6 participants for June 28th, then the booking will be successfully placed as it meets the minimum criteria and no other places will still remain for further booking.
