# Canada Post Labels for Multiple Packages with WooCommerce

Shipping is one of the most important aspects of online business. For a WooCommerce store owner, WooCommerce provides a lot of in-built shipping features. Unfortunately, allowing store owners to print a shipping label, isn’t one of them. However, the WooCommerce Canada Post Shipping plugin is a complete shipping solution that allows store owners to print shipping labels. With an easy-to-use interface and tons of advanced features, the WooCommerce Canada Post Shipping plugin is one of the best shipping solutions for WooCommerce.

In this article, we will cover the [WooCommerce Canada Post Shipping Plugin’s](https://www.pluginhive.com/product/woocommerce-canada-post-shipping-plugin-with-print-label/) ability to allow store owners to print shipping labels. This way, a store owner can easily print shipping labels in case some customer buys multiple products that are packed in multiple boxes.

## Single and Multiple Packages

The number of packages that the store owners have to ship, depends on the way they pack their products. WooCommerce Canada Post Shipping plugin has a built-in feature known as the ‘**Parcel Packing Method** ‘. This option allows store owners to select how they want to pack their products while shipping. By default, it has the following options,

  * **Pack Individually**  
This option is generally used by small business owners only. If store owners select this option, all the products will be packed separately, irrespective of the weight and dimensions of the product. Hence, the total package will be equal to the number of products in the cart.
  * **Pack into Boxes with custom Weight and Dimensions**  
This option is suitable for those store owners who have dedicated boxes to pack their products. After selecting this option, the store owner has to add shipping boxes with custom weights and dimensions. If the product’s dimensions and weight match the box dimensions and weight, the product will be packed in that box. All the products will be packed in the same box until the dimensions or weight limit is reached. This way there will be only one package for shipping. Once the total weight or dimensional limit is reached, the products will be packed into another box and a new package will be created.
  * **Weight-Based Packing  
** This packing method is suitable for almost every business. If store owners select this packing method, they will have to add a **Max Weight** in the plugin settings. Any product whose weight is less than Max Weight will be packed in one box and will be considered as one single package only. Only when the product’s weight exceeds the Max Weight, a new package will be created.

So based on the above packing methods, store owners can select a packing method suitable for their business. This way, store owners can be sure of exactly when multiple packages will be created.

## Printing Shipping Labels using the WooCommerce Canada Post Shipping plugin

WooCommerce Canada Post Shipping plugin allows store owners to print shipping labels for both domestic as well as international shipping. By default, it supports the following shipping label sizes,

  * 8.5 x 11
  * 4 x 6 (Only for Contract users)

These are the standard sizes for a Canada Post Shipping Label. Moreover, this plugin also allows store owners to print and send Return Shiping Labels to their customers.

* * *

### Shipping Label for a Single Package

We will be considering the ‘Box Packing with Custom Weight and Dimensions’ Parcel Packing method in this article. The image below shows the box, **‘Box 1’** with custom weight and dimensions that we will be using in this article.

So based on this packing method, if a product can be packed in one box, the store owners need to print the shipping label for only one package. After placing the order, store owners can print a shipping label by clicking on the **Order** and clicking on ‘**Create Shipment** ‘. On clicking this option, the plugin will send the details regarding the product’s weight and dimension, as well as the number of packages. This way Canada Post will generate shipping labels based on these details.

The store owners will be able to download and print a single shipping label by clicking on **Print Label** option on the Orders page.

* * *

### Shipping Labels for Multiple Packages

Based on the box packing method, if the weight and dimensions of a product/multiple products exceed the dimension and weight limit of a single box, then they need to be packed in multiple boxes. Hence, upon clicking the ‘**Create** **Shipment** ‘, the plugin will send the number of packages, and multiple shipping labels will be generated.

The store owners will be able to download and print all the shipping labels by clicking on the **Print Label** option on the Orders page.
