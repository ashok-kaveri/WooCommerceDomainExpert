# How to Setup an eLearning Store using WooCommerce Bookings and Appointments plugin?

In this article, we will check out how easy it is to set up an eLearning store using WooCommerce Bookings and Appointments plugin. It will also cover the functionalities of the plugin like the Assets and Resources, in order to set up a perfect online store where you can sell lessons to your customers.

## Business Case…

So considering the eLearning store, there are a few things that you would require to set up the store. These things include,

  * **Number of Teachers**
  * **Different Types of Lessons**
  * **Lesson Availability and Duration**

### Number Of Teachers

An online learning store can have multiple teachers which may have a limited number of lessons per day available for the students. Hence, it becomes difficult to handle different teacher’s appointment such that the bookings would not get overlapped.

In order to set up different teachers, you can easily use the Bookings Assets feature of the WooCommerce Bookings and Appointments plugin. Click here to read more about the [**Booking Assets and How To Create an Asset**](https://www.pluginhive.com/knowledge-base/how-to-set-booking-assets-using-woocommerce-bookings-and-appointments-plugin/).

### Different Types of Lessons

Similar to the teachers, you also require to list out all your lessons so that the students can easily distinguish and proceed with the booking for the required lesson only.

For listing out the lessons, you can use the Booking Resources feature of the WooCommerce Bookings and Appointments plugin. Click here to read more about the [**Bookings Resources and How To Set up Resources**](https://www.pluginhive.com/knowledge-base/how-to-set-booking-resources-using-woocommerce-bookings-and-appointments/).

### Lessons Availability and Duration

Once you are done with setting up the teachers and lessons, the next most important task is to define the booking availability and the duration of the lessons.

This can be achieved using the Booking Availability feature of the WooCommerce Bookings and Appointments plugin. You can click here to read more about [**How To Set Bookings Availability**](https://www.pluginhive.com/knowledge-base/how-to-set-bookings-availability-using-woocommerce-bookings-and-appointments/).
