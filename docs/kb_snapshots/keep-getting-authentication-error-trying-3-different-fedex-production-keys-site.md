# How to Resolve Authentication Error with FedEx Production Keys

In this guide, we will help you solve the Authentication error with FedEx Production keys when using the **[WooCommerce Shipping Plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**. Read along to know more.

As you already know, the plugin displays FedEx Shipping estimates for both domestic and international shipments. It does that by working with FedEx APIs which calculate these estimates. But in order to do so and be able to print shipping labels, you need to move from the test environment to live.

With the FedEx production credentials, you can use your FedEx account to pay for the postage. You won’t be able to do that with your FedEx Test credentials. One of our customers was facing the following issue.

[](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)

[](https://www.pluginhive.com/product/shopify-fedex-shipping-app-with-print-label-tracking/)

[](https://www.pluginhive.com/magento-shipping-services/)

**Customer** :

I keep getting authentication errors after trying three different FedEx production keys for our site. Please help.

**PluginHive Support** :

Moving to live mode is an advanced service that requires authorization from FedEx. With our certified [WooCommerce Shipping Plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/), you don’t require to go through the FedEx Label Evaluation process separately. Please contact [PluginHive Customer Support](https://www.pluginhive.com/support/ "PluginHive support ") with the FedEx production details to complete the label evaluation process.

Ideally, you shouldn’t see the “Authentication Failed” error when generating a label using your FedEx production credential. We request you to kindly re-check your credentials and try again. If you need any help getting your production credential then kindly refer to our guide: [How to Get FedEx Production Credentials](https://www.pluginhive.com/get-fedex-production-credentials-enable-shipping-labels/).

* * *

Now, if you own a Shopify store and are looking for ways to integrate FedEx shipping then check out Shopify Shipping App for FedEx. **[Shopify Shipping App for FedEx](https://apps.shopify.com/fedex-shipping)** is an end-to-end FedEx shipping solution for your Shopify-based store.

This App works in a similar way as the **[WooCommerce Shipping plugin for FedEx](https://www.pluginhive.com/product/woocommerce-fedex-shipping-plugin-with-print-label/)**. With the help of this App, you can show real-time shipping rates on your Checkout page.

If you need any help setting up FedEx shipping on your WooCommerce or Shopify store, feel free to **[Contact PluginHive Customer Support](https://www.pluginhive.com/support/)**. We would be more than happy to help.

_Good luck!_
